# 💍 소희성우 결혼비용 대시보드 셋업 가이드

---

## 1단계 — 구글 시트 만들기

1. [Google Sheets](https://sheets.google.com) 열기
2. 새 스프레드시트 생성
3. **`결혼비용_템플릿.csv`** 파일을 **파일 → 가져오기**로 불러오기
   - "현재 시트 교체" 선택
4. 이제부터 이 시트에 금액, 날짜 입력!

### 컬럼 구조
| 컬럼 | 설명 | 예시 |
|------|------|------|
| 이름 | 항목명 | 웨딩홀 |
| 카테고리 | 고정값 그대로 유지 | 🏰웨딩홀 |
| 예정금액 | 예상 지출 금액 (원 단위) | 5000000 |
| 지출금액 | 실제 지출한 금액 | 2500000 |
| 계약금 | 계약금 납부액 | 500000 |
| 계약금지급일 | YYYY-MM-DD 형식 | 2026-03-15 |
| 잔금 | 남은 잔금 금액 | 4500000 |
| 잔금지급일 | YYYY-MM-DD 형식 | 2026-08-01 |
| 메모 | 자유 입력 | 강남구 예식장 |

---

## 2단계 — 구글 시트 웹 공개

1. 구글 시트 상단 메뉴 **파일** 클릭
2. **공유 → 웹에 게시** 클릭
3. "링크" 탭에서 형식을 **CSV**로 변경
4. **게시** 버튼 클릭
5. 생성된 URL 복사 (이게 대시보드에 들어갈 URL!)

> ⚠️ "웹에 게시"는 "공유"와 달라요. 반드시 **웹에 게시** → CSV URL을 써야 해요.

---

## 3단계 — GitHub Pages 배포

1. [GitHub](https://github.com) 계정 만들기 (없다면)
2. **New Repository** 클릭
   - 이름: `wedding-cost` (또는 원하는 이름)
   - Public 선택
   - README 추가 체크
3. **`index.html`** 파일을 레포지토리에 업로드
   - "Add file" → "Upload files" → index.html 드래그
4. **Settings → Pages** 클릭
   - Source: "Deploy from a branch"
   - Branch: main, / (root)
   - Save
5. 잠시 후 `https://[깃허브아이디].github.io/wedding-cost` 주소로 접속!

---

## 4단계 — 대시보드에 구글 시트 연결

1. 배포된 GitHub Pages URL 접속
2. 오른쪽 하단 **⚙️ 버튼** 클릭
3. 2단계에서 복사한 CSV URL 붙여넣기
4. **저장 후 새로고침** 클릭
5. 🎉 완성!

> 이후 구글 시트에서 데이터를 수정하면 페이지 새로고침만 해도 바로 반영돼요.
