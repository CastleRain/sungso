Telegram 비공개 알림

iPhone · Android
  1. BotFather에서 새 봇을 만들고 토큰을 받습니다.
  2. 두 사람만 있는 비공개 그룹에 봇을 추가하고 메시지 하나를 보냅니다.
  3. getUpdates로 그룹의 chat_id를 확인합니다.
  4. GitHub 저장소 Settings → Secrets에 TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID를 저장합니다.
  5. 필요하면 Settings → Variables에 HOMEHUNT_ALERT_DISTRICTS 등 지역·가격·면적·세대수·신혼 조건을 넣습니다.
  6. 예약 수집이 조건에 맞는 새 공고·중요 변경을 찾으면 두 휴대폰 Telegram으로 보냅니다.

토큰과 chat ID는 페이지·코드·대화창에 붙여 넣지 말고 GitHub Secrets에만 넣으세요. 브라우저의 ‘내 조건’은 개인 기기 저장이라 Telegram 조건과 자동 동기화되지 않습니다.
