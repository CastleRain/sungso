# 회사 위치 기반 추천 로직 검토

2026-09-06 · 화면 4.0.1 · 읽기 전용 코드 리뷰. 제품 코드는 수정하지 않았다.

## 결론

한 회사만 보는 구조는 아니다. 최대 4개 목적지 전체를 기준으로 후보를 선별하고, 모든 필수 목적지의 실제 경로가 제한시간 안일 때만 통근 충족으로 판정한다. 다만 조건 수정과 부분 실패에서 실제 결과를 잘못 유지하거나 제외하는 오류가 있어, 현재 상태를 완전히 검증된 회사 기반 추천으로 보기는 어렵다.

## 추가 확인 사항

- **저장 경로의 시간 만료가 없다.** `candidateVerificationStatus()`는 목적지 fingerprint와 명시적 stale만 확인하고 `verifiedAt` 경과시간을 검사하지 않는다. 오래된 저장 경로도 날짜가 같은 최신 조회처럼 최종 확인 상태를 유지한다. 서버의 대중교통 8시간·자동차 20분 캐시 정책과 별개로, 브라우저 저장 판정의 신선도 정책이 필요하다. (`recommendation-verification-core.mjs:77`)
- **도보 정보 없음이 0분으로 바뀐다.** 공급자 또는 균형 계산에서 누락된 도보를 0으로 정규화해 도보 부담이 없는 것처럼 점수에 반영한다. 미확인 값은 별도 상태로 보존해야 한다. (`scripts/commute-provider.mjs:451`, `js/commute-balance-core.mjs:165`)
- **좌표를 나중에 얻은 카드의 개별 통근 버튼이 무반응일 수 있다.** 지도 이동은 상태의 후보 객체를 교체하지만 기존 버튼은 좌표 없는 예전 객체를 참조한다. 클릭 시 ID로 최신 후보를 읽고 실패 이유를 안내해야 한다. (`app.js:6589`, `6803`, `5817`)
- 백엔드 mock 검사에서는 응답 본문 파싱 전에 타임아웃을 해제하는 문제와, 배치 사전검사 직후 캐시 만료 시 `maxTransitCalls:0`을 넘겨 1회 원호출하는 경계 문제도 확인했다. (`scripts/commute-provider.mjs:563`, `scripts/local-market-server.mjs:844`)

## 정상 동작과 설계 한계

- 가격·전용면적·세대수·연식은 국토부와 공식 단지 자료로 먼저 판정한다. 회사 위치는 이후 지도 좌표와 실제 경로 선별에 쓰인다.
- 여러 목적지의 최악 직선거리, 가중 평균거리로 실제 경로를 조회할 후보를 추린다. 직선거리만으로 60분 통근 충족을 만들지 않는다.
- 확인된 경로는 최악 소요시간/허용시간 비율을 먼저 줄이고 가중 평균시간으로 다음 순위를 정한다. 도보·환승은 보조 점수다.
- Kakao 1차 선별과 TMAP 최종 검증은 분리돼 있다. 실제 경로 공급자 오류 뒤 제한된 TMAP을 자동 소진하지 않도록 중단한다.
- 경로 조회는 일부 후보에 한정된다. TMAP은 상위 최대 2곳, 자동차는 최대 10곳 등 한도와 공간 분산을 사용하므로 서울·경기 전체에서 통근 최적해를 보장하는 알고리즘은 아니다.
- 가격 후보 600개 초과에서는 좌표 준비 전체를 중단하므로 조건을 좁혀야 한다. 공식 카탈로그 자체의 좌표 커버리지가 없어 지오코딩 성공 여부에도 영향을 받는다.
- 현재 UI의 교통수단·허용시간·출발시각은 목적지 공통이다. 회사마다 다른 제한이나 교통수단을 쓰는 입력 UI는 없다. 주당 방문일만 개별 설정한다.

## 검증 범위

- 관련 기존 자동 테스트 **49개 통과**. 대체 수단 미확인인데도 제외를 기대하는 테스트가 있어, 통과 자체가 위 오류의 부재를 뜻하지 않는다.
- 실제 `app.js` 함수를 추출한 메모리 실행으로 회사 수정 후 이전 조건 유지, 순수 모듈로 주당 방문일 가중치·대체 수단 미확인·오래된 경로 상태를 재현했다.
- 재현 스크립트: Git 제외 `.local/review-commute-ui.mjs`.
- 로컬 health에서 공급자 키 설정과 남은 한도만 확인했다. 이 실행의 공급자 진단은 null이며 오늘 TMAP 0/10, Kakao 0/1000이다. 설정 여부를 실연결 성공으로 간주하지 않았다.
- 실제 회사·저장 후보·사용자 조건은 수정하지 않았고 이번 리뷰의 외부 경로 API 원호출은 0회다.
