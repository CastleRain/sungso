# 공식 철도역 좌표 데이터

`data/rail-stations.json`은 국가철도공단의 **전체_도시철도역사정보_20260630.xlsx**를 정규화한 공개 정적 자료다. 2026-09-06에 공식 파일을 직접 내려받았다. 회사 위치 API, 경로 API, 인증키와 `.env`를 사용하지 않는다.

## 출처와 이용 조건

- 제공: 국가철도공단 철도산업정보센터·전국 도시철도 운영기관. [철도데이터포털 원본](https://data.kric.go.kr/rips/M_01_01/detail.do?id=32), [공식 XLSX 다운로드](https://data.kric.go.kr/rips/dataset/download.file?type=filedata&id=32&operation=1).
- 메타데이터·라이선스: [전국도시철도역사정보표준데이터](https://www.data.go.kr/data/15013205/standard.do). 이용허락범위 제한 없음, 무료. 역사명, 노선, 좌표, 운영기관, 도로명주소와 데이터기준일자를 제공한다.
- 공공데이터포털의 카탈로그 설명은 과거 파일명을 표시할 수 있다. 실제 받은 원본 파일명·파일 SHA-256·조회시각을 JSON `source`에 별도 보존한다.
- 파일명의 `20260630`은 파일 기준일이다. 게시일로 확인하지 않았으므로 `publishedDate:null`, `referenceDate:'2026-06-30'`로 구분한다. 개별 역의 `updatedAt`은 각 원본 행의 기준일이며 파일 기준일로 덮어쓰지 않는다.

## 범위와 제외

원본 1,099행에서 **노선별 역사 1,090행**을 제공한다. 집 후보는 서울·경기로 한정하더라도 가까운 역이 인천·충남 등에 있을 수 있으므로 역 자료에는 전국 유효 행을 포함한다. 서울 405행, 경기 268행, 인천 95행, 충남 11행 등이 포함된다. 일부 지방 역의 주소에는 시도명이 없어서 `regionName:null`을 유지한다. 역명으로 지역을 추측하지 않는다.

환승역은 원본 노선별 좌표를 보존한다. 같은 이름만으로 합치거나 평균 좌표를 만들지 않는다. `stations.length`는 고유한 물리적 환승역 수가 아니다. 원본 노선번호를 서로 다른 노선명이 재사용하는 경우가 있어 ID는 `kric:노선번호:역번호:원본노선명`으로 만든다.

제외·정리한 9행은 다음과 같다.

- **양원역 1행:** 서울 중랑구 주소인데 원본 좌표가 `36.963729, 129.091321`로 서울·경기 범위를 벗어난다. 다른 자료나 임의 좌표로 고치지 않고 제외했다. 제외 원값과 이유는 `coverage.excludedCoordinateRows`에 남긴다.
- **이수 1행 중복:** 같은 노선·역번호·주소·운영기관·좌표의 이전 명칭 `총신대입구(이수)`와 최신 명칭 `이수`가 중복되었다. 최신 기준일 행을 대표로 남기고 이전 이름은 `aliases`에 보존했다. 좌표가 다른 동일 ID는 생성 오류로 처리한다.
- **자기부상철도 7행:** 인천시는 2025년 10월 17일 재개하면서 기존 도시철도에서 체험형·공항이동지원형 궤도시설로 전환했다고 밝혔다. 일반 도시·광역철도 접근성 범위에서 제외한다. [인천시 공식 운영 재개 보도자료](https://www.incheon.go.kr/mayor_9/MA05010000/view?repSeq=DOM_0000000013303245).

원본에는 GTX 노선이 없어 포함하지 않는다. 역 자료만으로 최신 개통·휴업·시간표·배차·출입구 개방 상태를 검증하지 않는다. 표시 문구는 **“공식 자료에 수록된 역 중 가까운 역”**으로 유지한다. 계획역의 예상 위치를 추가하지 않았으며, 원본 이름·노선·주소에 예정·미개통·폐지·운행중단 표시가 있으면 생성 단계에서 제외한다.

## 좌표와 거리의 의미

`lat`/`lng`는 원본의 `역위도`/`역경도`를 숫자로 옮긴 값이며 소수점을 새로 생성하거나 반올림하지 않는다. 원본은 출입구 번호와 지리좌표계의 상세 메타데이터를 제공하지 않으므로 `coordinateType:'station'`, `coordinateRole:'official-station-reference'`로 표현한다.

이 값은 **역사 대표 좌표까지의 직선거리**에만 사용한다. 실제 도보거리·도보분·출입구 접근·열차 소요시간·환승시간으로 표시하지 않는다. 정확한 단지 좌표가 없는 구·동 대표점에는 역거리를 계산하지 않는다. 기존 아파트 카탈로그 17,851행에는 원본 좌표가 없어서 별도로 확보한 단지 좌표가 있어야 계산할 수 있다.

강남 접근성의 기준점 `anchor`는 공식 **2호선 강남역** 행의 `37.49805, 127.02795`다. 해당 행의 기준일 `2024-12-31`도 함께 보존한다. 신분당선 강남역과 임의로 평균내지 않는다. 강남 전체 업무권이나 실제 강남 통근시간을 대신하지 않는다.

## 재생성·검증

Node.js 내장 기능만 사용한다. 공개 XLSX 다운로드 1회로 생성하며 별도 패키지 설치·인증·회사 API 호출이 없다.

```powershell
node homehunt/scripts/build-rail-stations.mjs
node homehunt/scripts/build-rail-stations.mjs --inspect
node homehunt/scripts/build-rail-stations.mjs --input C:\path\전체_도시철도역사정보_20260630.xlsx
node --test homehunt/scripts/build-rail-stations.test.mjs
```

XLSX 열 순서, ZIP 형식·크기, 유효 좌표, ID 충돌, 강남 기준점, 최소 행 수를 확인한 뒤 JSON을 쓴다. 숫자형 Excel 날짜와 `YYYYMMDD`는 날짜로 정규화하며 `1900-01-00` 등 잘못된 기준일은 `updatedAt:null`과 `sourceDateRaw`로 남긴다. ZIP이 아닌 오류 HTML이나 변경된 시트 형식은 데이터로 저장하지 않는다. 분기마다 원본 갱신 여부와 개별 역 날짜·범위를 검토하는 용도이며, 실행 시 자동 스케줄·무제한 재시도를 만들지 않는다.
