# 집 찾기 지역 분포·입지 추천 (UI 4.2)

기본 정렬은 가격이 싼 순서에서 입지 추천순으로 변경했다. 회사 위치는 필요하지 않으며 등록한 회사의 실제 통근 검증은 별도 기능이다. 검색한 가격·면적·세대수·연식 조건을 통과한 후보만 비교한다.

## 점수

| 항목 | 기본 | 강남 우선 | 역 우선 |
|---|---:|---:|---:|
| 강남역 직선거리 | 45 | 65 | 30 |
| 수록 역 중 가장 가까운 역 직선거리 | 30 | 15 | 50 |
| 단지 세대수 | 10 | 8 | 8 |
| 연식 | 10 | 7 | 7 |
| 예산 충족 | 5 | 5 | 5 |

합계 100점의 고정 선호 가중치다. 학습한 투자 모델이나 가격 상승 예측이 아니다. 예산을 충족하면 동일한 예산 점수를 주므로 더 저렴하다는 이유로 외곽 단지가 유리해지지 않는다. 거리·규모·연식의 구간 보간 함수는 `js/location-ranking-core.mjs`에 있다. 기본 강남 거리는 5·10·15·20·30·40km, 역 거리는 300·600·1,000·1,500·2,500m에 따라 점차 가점이 줄어든다.

미확인 항목은 0점이고 다른 항목의 비중을 늘려 보상하지 않는다. 지역 대표점은 강남 거리만 낮은 신뢰 가중치(시군구 0.35, 동 0.65)로 참고하고 역거리는 계산하지 않는다. 카드의 `지역 참고`와 `입지 추천`을 구분한다. `점수 항목 N% 확인`은 점수 산출 자료의 확보 비중이며 경로 검증·구매 적합성의 확률이 아니다.

## 위치 확인과 지도

- 모든 후보는 주소의 시군구로 집계한다. 지도 숫자는 해당 지역의 조건 후보 수이며 판매 중인 매물 수가 아니다.
- 넓은 지도에서는 가까운 지역 대표점을 숫자 묶음으로 표시하고 클릭하면 확대한다. 단일 지역 또는 목록을 선택하면 해당 시군구로 후보 목록과 지도를 좁힌다.
- 단지 카탈로그에 좌표가 없는 경우 지역 대표점을 먼저 확보하고 강남 접근성을 기준으로 상위 40곳의 주소를 확인한다. 추가 버튼은 현재 선택 지역·정렬 범위에서 미확인 상위 20곳을 확인한다. 동시 주소 조회는 2개로 제한하고 기존 캐시를 재사용한다.
- 지역 숫자에는 좌표 미확인 후보도 포함한다. `단지 위치 지도`는 실제 단지 좌표를 확보한 후보만 표시한다. 지도에 핀이 없다고 해당 지역의 후보가 없는 것은 아니다.
- 좌표를 추가 확인하면 순위가 바뀔 수 있다. 일부 좌표를 확인한 상태의 상위 후보를 전체 993곳의 확정 최상위라고 표현하지 않는다. 관심 지역을 먼저 좁힌 뒤 추가 위치 확인으로 비교 범위를 보완한다.
- 늦게 도착한 주소 응답은 새 검색·관심 목록 변경·경로 결과를 덮어쓰지 않는다. 입지 계산 과정에서는 TMAP·Kakao 실제 경로를 자동 조회하지 않는다.

## 역 자료와 한계

[공식 철도역 자료](rail-station-data.md)는 국가철도공단 원본의 노선별 역사 1,090행이다. 환승역 노선별 행을 보존했으므로 고유한 물리적 역 1,090개라는 뜻은 아니다. 경계 지역에서 인천·충남 역을 놓치지 않도록 전국 자료를 사용한다. 원본에 GTX는 없으며 역별 자료 기준일도 서로 다르다.

강남 기준은 공식 2호선 강남역 좌표다. 모든 거리는 직선거리이며 출입구까지 도보거리, 강·고속도로 횡단 가능성, 열차 배차·환승·실제 통근시간을 뜻하지 않는다. 실제 이동 확인이 필요한 후보는 기존 목적지별 경로 검증으로 이어간다.

## 검증

순수 점수·좌표 서비스, 목적지 없는 검색, 검색/관심 목록 변경 중 비동기 응답 격리와 지도 갱신 경합을 자동 검증한다. 공식 XLSX 생성 검증은 일반 tests 폴더 밖에 있으므로 다음 명령에 명시적으로 포함한다.

```powershell
node --test homehunt/tests/*.test.mjs homehunt/scripts/build-rail-stations.test.mjs
```

2026-09-06 검증: 전체 자동 테스트 355개 통과. 현재 사용자 조건에서 993곳·36개 시군구, 지도 클러스터/지역 목록의 합계 일치, 만안구 23곳 선택, 기흥구 상위 20곳 추가 위치 확인과 강남/역/가격 정렬·상세 점수 연동을 실화면 확인했다. 데스크톱·390/430px 모바일 무가로넘침, 브라우저 오류 없음. 기존 필터·목적지는 유지했다.
