# 부동산 대시보드

## 무엇을 볼 수 있나요?

대시보드는 집값을 예언하는 점수판이 아니라, 현재 예산으로 집을 살 여력과 관심 지역의 거래 상황을 함께 확인하는 화면입니다. 금리·거래·수급 지표를 누르면 뜻, 상승·하락 시 해석, 함께 확인할 항목과 출처를 볼 수 있습니다.

| 항목 | 표시 자료 | 해석할 때 확인할 점 |
|---|---|---|
| 은행 주택담보대출 평균금리 | 한국은행 ECOS의 예금은행 신규취급액 기준 가중평균 | 전국의 관측월 평균이며 개인에게 제시된 오늘의 견적이 아닙니다. |
| 한국은행 기준금리 | 한국은행 공식 변경 이력 | 변경일과 자료 확인일을 분리합니다. 은행 대출금리에 그대로 적용되는 값이 아닙니다. |
| 아낌e보금자리론 30년 | 한국주택금융공사 해당 월 공시 고정금리 | 추가 우대 전 금리입니다. 주택·소득·만기 등 이용 요건을 따로 확인해야 합니다. |
| 수집된 매매 계약 건수 | 기존 국토부 공개 실거래 집계의 선택 지역·전 면적 | 수집한 9개 시군구 안에서 선택합니다. 서울·경기 전체 거래량이나 신고일 기준 국가승인통계와 다릅니다. |

| 분양·청약 기회 | 기존 서울·경기 공식 공고의 현재 접수·예정 상태 | 공고 수와 공급 세대수, 실제 입주 물량을 구분합니다. |

| 지역 입주 예정·공식 가격지수 | 해설과 공식 통계 확인 연결 | 자동 수집하지 못한 값을 0이나 임의 값으로 표시하지 않습니다. 지역·기준월·통계 정의를 원문에서 확인합니다. |

## 금리와 집값의 관계

금리가 오르면 같은 대출의 월 상환액이 늘고 매수 여력이 줄어 집값에 하방 압력이 생길 수 있습니다. 다만 집값에는 지역 공급, 거주 수요, 소득·고용, 대출 규정, 향후 기대도 영향을 줍니다. 금리 인하가 경기 악화에 대응한 조치라면 금리는 내려가도 수요가 약할 수 있습니다. 전달에는 시차도 있습니다.

이는 한국은행의 통화정책 파급경로를 바탕으로 한 일반적인 설명입니다. 화면의 화살표와 조합 예시는 실제 표본에서 추정한 상관계수, 인과효과 크기, 가격 예측이 아닙니다. 수치가 함께 움직였다는 사실만으로 한쪽이 다른 쪽을 원인으로 만들었다고 결론내리지 않습니다.

## 상환 계산

- 집 찾기의 현재 목표 집값을 읽습니다. WeCost를 선택했다면 확인된 목표가격만 사용합니다. 계산기의 수정은 집 찾기·WeCost·클라우드 기록을 바꾸지 않습니다.
- 초기 대출 비중은 집값의 50%를 가정한 계산 예시입니다. 실제 대출 한도가 아닙니다. 금리는 확인된 은행 주담대 평균으로 시작하며 직접 받은 금리로 바꿀 수 있습니다.
- 만기 전체에 같은 연 금리가 유지되는 월별 원리금균등 상환을 계산합니다. 대출금 `P`, 월 금리 `r = 연 금리 / 1200`, 개월 수 `n`일 때 월 상환액은 `P × r / (1 − (1 + r)^(-n))`입니다. 금리 0%는 `P / n`입니다.
- 월 상환액·총이자·집값에서 대출을 뺀 자기자금과 금리 ±1%p의 월 부담을 비교합니다. 취득세·중개보수·수리비·중도상환수수료·거치기간·변동금리·DSR 심사는 계산에 포함하지 않습니다.

## 자료 갱신과 결측값

금리는 `update-homehunt-finance.yml`이 매일 한국시간 09:35에 공식 공개 자료를 확인합니다. GitHub 일정 실행은 지연될 수 있습니다. 화면의 새로고침은 공개된 JSON을 다시 읽으며 은행에 개인 금리 조회를 요청하지 않습니다.

ECOS 공개 sample 요청은 최대 10행이므로 조회 범위를 최근 10개월 이내로 제한합니다. 별도 API 키나 유료 DB를 추가하지 않습니다. 월평균은 공표 시차가 있으며 모든 항목에서 관측·적용일, 공표일(확인 가능한 경우), 확인 시각을 구분합니다. 원문 구조 변경·네트워크 실패 시 이전 값의 날짜를 유지하고 갱신 필요를 표시합니다.

실거래는 기존 일일 수집을 재사용합니다. 마지막 수집 월의 최근 두 달 이상을 변화 비교에서 제외하고, 비교에 필요한 월이 없거나 표본이 너무 적으면 보류합니다. 아직 신고되지 않은 거래를 0건으로 가정하지 않습니다. 공고 수집 실패 역시 접수 기회 0개로 처리하지 않습니다.

미분양·준공 참고자료는 `data/housing-indicators.json`에 관측월·공표일·확인일과 함께 저장합니다. 공식 지역별 통계의 안정적인 자동 수집 경로를 아직 연결하지 않아 월이 지나도 현재 수치라고 바꾸지 않습니다. 한국부동산원 가격지수의 장기 자동 수집에는 R-ONE Open API 인증키를 추가할 수 있습니다.
