# 비공개 매출 서비스

루트 지침을 따른다. 원본과 사용자 수치는 `sohee/` 밖의 Git 대상 파일로 옮기지 않는다. 이 서비스는 사용자가 요청한 매출 저장·갱신 범위만 담당한다.

- 원본 수집과 분석 재조회는 다르다. 토스 원본 없이 최신 거래를 생성하지 않는다.
- 기본 운영 쓰기는 비활성이다. 조회·빌드·서버 시작은 시딩하지 않는다.
- 원본 검증은 별도 후보에서 수행하고 기존 범위 바깥과 Payhere를 보존한다. 이전 원본·취소·출처 해시는 유지한다.
- 서버마다 Google/회원 상태를 확인하고, 실제 키·ID·매출·ZIP 암호를 기록하지 않는다.
- 무료 Firebase·Render 계약을 보존한다. 배포·초기 이전·자동 수집 앱 설치는 별도 검토한다.
- synthetic 테스트와 localhost Emulator만 쓴다. 실제 토스/통근 호출은 하지 않는다.

- 사용자가 정한 갱신 방식은 실행 시 로컬 토스 화면에서 원본을 받는 수동 절차다. `manual-update.md`를 따르고 토스 API·예약 작업을 추가하지 않는다. 위 실제 호출 금지는 개발 검증에 적용되며, 사용자의 명시적 수집 요청은 해당 범위의 로컬 화면 수집을 허용한다.
