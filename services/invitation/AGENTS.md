# 청첩장 방명록·커플 사진첩

- 사용자 승인: 이름과 축하 메시지를 모든 하객에게 공개한다. 최신 요청으로 두 사람만 쓰는 웹 관리 화면에서 사진 추가·순서 변경·공개 제외/복원을 제공한다. 하객 사진 업로드는 없다. 사진 설명 입력·시각 캡션은 제공하지 않는다.
- 방명록 공개 경로는 /api/invitation/v3/guestbook 및 UUID 삭제 경로만 허용한다. 앨범은 /api/invitation/v3/album의 선택 목록과 공개 선택된 UUID 사진 GET만 공개한다. manage/upload/publish 및 미공개 사진은 검증된 Google 토큰과 활성 sungwoo/sohee 역할을 요구한다. 기존 HomeHunt·회원 API의 인증과 CORS를 완화하지 않는다.
- 방명록 Admin 접근은 wedding_guestbooks/sungso_20270306 한 문서로 제한한다. 앨범은 wedding_albums/sungso_20270306 메타 문서와 그 photos/{UUID} 하위 문서만 사용한다. 클라이언트 Firestore 규칙을 공개하지 않는다. 읽기만으로 문서를 만들지 않는다.
- 이름·메시지만 공개 DTO에 포함한다. 삭제 토큰 원문은 기기만 보관하고 서버에는 해시만 저장한다. IP 원문은 저장하거나 기록하지 않는다.
- 전체 300개·하루 100개·기기당 하루 3개·60초 간격, 6KiB 요청, 읽기 캐시 15초를 유지한다. 게시 성공은 실제 서버 응답 후 표시한다.
- 실서비스에 검증용 글을 올리지 않는다. 메모리 Firestore와 별도 로컬 JSON 미리보기로 작성/삭제를 확인한다.

### 2026-10-20 — 청첩장 VER3.4 문 열기·사진첩 관리

- 음악 도구를 표지 아래/이야기 화면 안의 문서 흐름으로 옮겨 상단 겹침을 없앴다. 사용자 MP3 전체와 하나의 audio 요소를 유지하며 이야기 앞뒤 이동에서도 재생된다. 날짜 탭은 ‘남은 시간 / 예식 달력’, 사진 영역은 ‘사진첩’으로 정리했다.
- 초대글과 이야기 진입을 ‘우리의 이야기를 보실래요?’ 양문으로 합쳤다. 두 문이 950ms 동안 열리고 기존 사실만 담은 별도 이야기로 이동한다. Escape 취소·효과 끄기·모션 감소·브라우저 앞뒤·초점 복귀를 지원한다.
- 기존 두 Google 회원만 사용하는 /invitation-v3/manage.html을 구현했다. 사진 추가·순서 변경·공개 제외·보관함 복원·명시적 반영을 제공한다. 최신 사용자 요청대로 설명 입력과 시각 캡션은 제거했다. 초기 여섯 장과 운영 반영 목록을 한 사진첩에서 보여 준다.
