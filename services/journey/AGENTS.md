# 발자취 저장 서비스

[루트 지침](../../AGENTS.md)을 따른다. 이 서비스는 사용자가 요청한 공동 이동 기록·사진·수동 보완의 비공개 저장 범위다.

- Render의 기존 프로세스에 `/api/journey/v1`을 연결한다. 모든 읽기·쓰기·사진 응답 전에 기존 Google 토큰 및 활성 `sungwoo`/`sohee` 회원 검증을 실행한다. 청첩장 공개 Origin 허용을 이 API에 확대하지 않는다.
- `journey_private/shared`와 그 `days`, `months`, `photos` 하위 문서만 저장한다. 브라우저 직접 Firestore 접근은 기본 거부를 유지한다. 읽기만으로 문서를 만들지 않는다.
- 타임라인 원본 파일은 브라우저에서 처리한다. `shared/journey/core.mjs`의 KST 날짜·사람·출처·중복 검사 계약을 유지하고 원본 전체나 실제 개인 자료를 Git·로그·공개 자산에 넣지 않는다.
- 하루·월 요약·전체 색인·용량 장부는 한 트랜잭션으로 저장한다. 수정은 revision 비교를 하고 동일한 요청 재시도는 쓰지 않는다. 가져오기 중복은 수동 보완 내용을 덮어쓰지 않는다.
- 사진은 브라우저에서 줄인 JPEG만 받으며 서버에서 크기를 검증하고 Exif를 제거한다. UUID별 사진 바이트는 불변이다. 원본을 보관한다고 표시하지 않는다. 현재 한도와 API는 [README](README.md)에 기록한다.
- Spark·Render Free를 유지한다. Storage/Blaze 전환, 관리형 TTL, 자동 기동이나 별도 서비스는 추가하지 않는다. 운영 검증 쓰기 없이 메모리 DB 대역과 `demo-homehunt` Emulator로 검증한다.
