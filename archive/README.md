# 보관 자료

현재 앱 구현과 분리한 이전 버전·참고자료·작업 기록이다. 새 작업은 [현재 구조](../docs/architecture.md)와 앱의 `AGENTS.md`를 기준으로 한다.

| 폴더 | 보관 내용 |
|---|---|
| `history/` | 구조 정리 전 지침·README·세부 문서의 원본과 과거 진행 이력 |
| `wecost/` | Sheets 기반 백업·참고 HTML/CSV·이전 가이드 |
| `honeymoon/` | 독립 몰디브 보고서·원천 XML |
| `homehunt/homehunt-2.5-handoff/` | HomeHunt 2.5 인계 문서·화면 캡처 |

보관은 삭제나 실행 경로 복원을 뜻하지 않는다. 현재 웹 빌드는 등록부에 명시한 기존 공개 자료만 같은 URL로 출력하며 이 디렉터리 전체를 배포하지 않는다. 과거 문서의 배포 상태·검사 횟수·경로·가격·정책은 작성 당시 기록이다.
