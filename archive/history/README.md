# 이전 작업 기록

`2026-09-13-before-restructure/`는 앱·공통 코드·서비스 분리 직전의 기술 지침과 검증 기록을 보존한다. 현재 파일의 개인 여행 날짜·항공 시각·숙박 구성·견적 금액은 비공개 백업과 SHA-256 대조 후 일반화했다. 원문 백업은 Git 제외 경로에서 관리하며, 과거 Git 이력 자체를 변경한 것은 아니다.

- `root-AGENTS.md`: 루트 작업 지침과 2026-09-13까지의 진행 상황.
- `root-CLAUDE.md`: 초기 허브 기준 문서.
- `homehunt-AGENTS.md`, `homehunt-README.md`, `homehunt-docs/`: HomeHunt 전체 이전 지침·기능·운영·릴리스 기록.
- `wecost-CLAUDE.md`, `honeymoon-CLAUDE.md`, `travel-AGENTS.md`: 앱별 이전 문서.

여기의 날짜·경로·배포 상태·검사 횟수는 과거 기준이다. 현재 지침은 [루트 AGENTS](../../AGENTS.md), 구조와 실행 명령은 [현재 문서](../../docs/architecture.md)를 따른다. 원문 안의 이전 상대 링크는 이력의 일부로 유지한다.
