# 단지·생활 정보 추가 연결 안내

확인일: 2026-09-08 (KST). 로컬 HomeHunt UI 4.10 / API 2.8에서 사용자가 신청한 목록·기본 정보 서비스를 기존 `MOLIT_SERVICE_KEY`로 실제 연결했다. 죽전현대1차·용인죽전동부센트레빌·대원칸타빌1의 주소 일치와 기본/상세 응답을 검증했다.

## 현재 화면에 사용할 수 있는 정보

| 정보 | 현재 연결 | 표시할 때의 기준 |
| --- | --- | --- |
| 단지명·주소·세대수·준공연도 | 한국부동산원 공식 단지 CSV 기반 서울·경기 카탈로그 | 기준일이 있는 저장 자료. 현재 판매 중인 매물 수가 아님 |
| 정확 전용면적·평 환산·평균 거래가격·거래건수·최근 계약 | 국토교통부 매매·전월세 실거래 | 집 찾기는 매매 실거래로 후보를 계산. 일부 월 미완료는 잠정 가격으로 구분 |

| 관리비 | 미연결 | 공용관리비·개별사용료는 별도 서비스·대상 월의 연결 필요 |

화면 구성과 필터 접근성 개선에는 새 API가 필요하지 않다. 단지·생활 정보 자동 보강에는 아래 공식 서비스를 연결한다.

## 연결한 두 서비스

| 순서 | 정확한 신청 서비스 | 활용할 내용 | 공식 신청 페이지 |
| --- | --- | --- | --- |
| 1 | 국토교통부_공동주택 단지 목록제공 서비스 | 지역·주소별 K-apt 단지 목록과 단지코드 확보. 현재 카탈로그와 같은 단지인지 연결 | [활용신청](https://www.data.go.kr/data/15057332/openapi.do) |
| 2 | 국토교통부_공동주택 기본 정보제공 서비스 | 기본 정보와 상세 정보 모두 포함. 세대수·동수·난방방식, 승강기 대수, 지상/지하 주차대수, 부대·복리시설, 주변 교통·생활시설 등 | [활용신청](https://www.data.go.kr/data/15058453/openapi.do) |

두 서비스의 현재 신청 페이지는 무료, 개발·운영 자동승인, 개발계정 신청 가능 트래픽 5,000회로 안내한다. [전국공동주택표준데이터의 기능 명세](https://www.data.go.kr/data/15096285/standard.do?recommendDataYn=Y)에서도 상세 조회의 승강기·지상/지하 주차·교통·시설 필드를 확인할 수 있다. 이 표준 페이지의 예전 한도 10,000회와 직접 신청 페이지의 한도가 다르므로 실제 승인 화면에 표시되는 최신 한도를 기준으로 설정한다.

기본·상세는 `공동주택 기본 정보제공 서비스` 한 신청 안의 두 기능이다. 2025년 변경 공지는 V4였지만, 현재 두 신청 페이지의 Swagger(2026-08-07 수정)는 아래 목록 V4·정보 V5를 제공한다. 실제 호출도 이 최신 버전으로 성공했다.

- 목록 조회: `https://apis.data.go.kr/1613000/AptListService4/getSigunguAptList4`
- 기본 조회: `https://apis.data.go.kr/1613000/AptBasisInfoServiceV5/getAphusBassInfoV5`
- 상세 조회: `https://apis.data.go.kr/1613000/AptBasisInfoServiceV5/getAphusDtlInfoV5`

현재의 REB 카탈로그 `catalogId`를 K-apt `kaptCode`로 그대로 사용할 수 없다. 주소·식별정보로 동일 단지 연결을 확인한 뒤 같은 K-apt 코드의 세대수와 지상·지하 주차대수를 결합한다. 세대당 주차대수는 `(지상 + 지하) / 세대수`로 계산하되 구성 값이 없으면 미확인으로 남긴다. 실제 차량 등록 가능 대수·추가 주차요금·야간 혼잡도는 별도 확인 사항이다.

K-apt에 가입한 단지의 자료이며 모든 아파트의 모든 필드가 채워진다는 보장은 없다. [K-apt 시스템 소개](https://www.k-apt.go.kr/cmmn/kaptsystemintro.do)에 안내된 대상 범위를 고려해 미매칭·누락을 후보 탈락이나 주차 불가로 처리하지 않는다.

## 관리비를 비교하려면 추가할 선택 서비스

| 서비스 | 활용할 내용 | 신청 페이지 |
| --- | --- | --- |
| 국토교통부_공동주택관리비(공용관리비)정보제공서비스 | 단지의 월별 공용관리비 비교 | [활용신청](https://www.data.go.kr/data/15057937/openapi.do) |

공용관리비는 특정 가구가 실제 납부하는 총 관리비와 다르다. 세대당·면적당 환산값을 표시한다면 대상 월, 원래 집계 범위, 계산 방법을 함께 밝힌다. 전기·수도·난방 등의 사용료까지 분석하려면 [국토교통부_공동주택관리비(개별사용료)정보제공서비스](https://www.data.go.kr/data/15059469/openapi.do)도 별도 검토가 필요하다. 단지 합계로부터 특정 집의 실제 고지액을 확정하지 않는다.

층수·용적률·건폐율 등 건축 제원 확장은 이후 [국토교통부_건축HUB_건축물대장정보 서비스](https://www.data.go.kr/data/15134735/openapi.do)를 검토한다. 총괄표제부·표제부·층별개요 등 서로 다른 단위의 자료를 제공하므로 단지와 동의 구분 및 식별자 매칭이 선행되어야 한다.

## 키와 승인 상태

먼저 기존 실거래에 사용하는 공공데이터포털 계정에서 위 목록·기본 정보 두 서비스를 각각 추가 활용신청한다. 저장소의 기존 설정 방식은 공공데이터 일반 서비스키를 사용하는 구조이므로, 같은 개인/프로젝트 서비스키를 선택해 연결할 수 있는지 승인 현황에서 확인한다.

기존 Git 제외 로컬 설정의 `MOLIT_SERVICE_KEY`로 세 기능 모두 호출 성공했다. 별도 키 추가는 필요하지 않았다. 비밀값은 브라우저·응답·공개 캐시에 포함하지 않는다. 키가 설정됐다는 사실과 실제 조회 진단은 `/api/health.officialComplex`에서 구분한다.

## 구현 상태와 다음 순서

4.11에서는 같은 법정동·지번·단지 차수·세대수가 확인될 때만 지역명 접두어나 제한된 주공/주공그린빌 명칭 차이를 허용한다. 실제 금화마을5단지주공그린빌을 공식 금화마을주공5단지(681세대)와 연결하여 주차 681대(지상 166·지하 515), 지역난방, 승강기 17대를 확인했다. 여러 단지가 함께 등록된 청명호수마을신안인스빌1,2단지는 1단지의 개별 시설값으로 연결하지 않는다. 관련 공식 목록 이름과 통합 범위를 안내하고 주차 점수는 보류한다. 같은 차수·주소·세대수 근거가 없는 유사 명칭이나 복수 후보는 여전히 미확인이다.

로컬 `GET /api/kapt/complex?catalogId=...`가 서버 공식 카탈로그를 기준으로 조회한다. 클라이언트가 보낸 임의 주소·K-apt 코드는 매칭 근거로 쓰지 않는다. 같은 법정동·명칭/공식 별칭·지번 또는 도로명 주소를 대조하며, 중복·불확실 매칭은 점수에 넣지 않는다. 상세 `useYn=Y`와 동일 K-apt 코드의 세대수를 확인한 뒤 지상·지하 주차를 합산한다.

`scripts/kapt-provider.mjs`는 목록 7일, 기본/상세 1일 동안 `.local/market-cache/kapt`의 공개 필드만 재사용한다. 동시에 같은 정보를 요청하면 한 번만 조회한다. 새 시군구의 첫 단지는 목록 + 기본 + 상세(목록 페이지가 많으면 추가 요청), 같은 시군구의 다른 단지는 기본 + 상세, 유효 캐시가 있는 같은 단지는 신규 0회다. 저장 후보부터 우선 확인하고 새 검색의 가격 후보 전체를 이어 조회한다. 같은 단지의 여러 평형·저장/검색 중복은 한 번만 확인하며 지도 지역·통근 필터·목록 표시 수로 대상을 자르지 않는다. 공급자 전체에서 동시 외부 요청은 최대 2개, 요청 시작 간격은 200ms다. 실패한 상세는 성공한 기본정보를 보존하고 명시적으로 재시도한다.

`js/official-complex-queue.mjs`는 단지별 확인·일부·미매칭·실패·대기 건수와 일시정지/재개/미완료 재시도를 제공한다. 권한·한도 오류는 즉시 멈추고 일시적인 오류가 연속되면 나머지를 대기로 남긴다. 일부 시설 미확인 때문에 가격 후보나 이미 확인한 통근을 지우지 않는다. 같은 조건 재검색에서 유효 결과를 유지하고 만료된 공공정보만 다시 확인한다. 아직 가격이 확인되지 않은 1차 카탈로그 전체는 자동 시설 조회 대상이 아니다.

`js/official-complex-client.mjs`와 목록·상세 패널은 이 공개 근거를 현재 후보 점수와 목록에 연결한다. 회사 주소·통근 경로는 K-apt 요청/캐시에 들어가지 않는다. 공공 주차 자료를 보거나 새로고침 후 재사용하는 데 Kakao 호출은 없다. 자동 테스트는 가상 응답을 사용한다. 실제 검증 단지의 주차는 각각 죽전현대1차 705/702대, 용인죽전동부센트레빌 575/536대, 대원칸타빌1 292/394대(총 주차/세대수)였다.

저장된 6곳 모두 주차·난방·승강기 연결을 실화면에서 확인했다. 같은 조건의 새 가격 후보 574곳과 저장 집을 합쳐 중복 제외 579곳을 실제 자동 조회했고, 공식 연결 249곳·단지 대조 미확인 330곳·조회 실패 0곳이었다. 미매칭 330곳도 가격 후보로 유지하며 공공정보가 없다는 이유로 통근 충족이나 주차 불가를 판정하지 않는다. 공개 캐시 5곳을 점검했을 때 지역명이 붙은 단지명, 신·구 지번 차이, 지번 누락, 법정동 변경, 여러 단지 통합 등록 등이 확인됐다. 전체 330곳의 원인을 분류한 것은 아니며, 명칭만 비슷하다고 자동 연결하지 않는다. 다음 단계는 미매칭 후보의 공식 주소·명칭 근거를 보강하고, 별도 관리비 서비스를 대상 월·범위와 함께 연결하는 것이다. 공개 Pages의 K-apt API는 아직 활성화하지 않았다.

네이버부동산의 상단 필터·지도 탐색 방식은 UI 참고 대상으로 활용한다. 국토부 실거래 평균은 현재 매물 호가가 아니며, 네이버의 매물 수·매물 사진·판매 상태를 공공 API가 제공한다고 안내하지 않는다.
