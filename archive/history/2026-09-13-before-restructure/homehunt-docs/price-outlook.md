# 예상가격 표시 방식 — UI 4.17

2026-09-10 기준. `실거래 → 예측·근거`에서 같은 단지·거래유형·전용면적의 실제 가격과 참고 전망을 표시한다. 실제 계약금액과 미래 추정값을 구분하며 매물 호가·감정평가로 사용하지 않는다.

## 표시하지 못했던 이유

기존에는 조회기간과 학습기간이 같았다. 최근 1년은 학습·검증 사례가 부족하고, 최근 3년도 현재월·직전월을 제외하면 34개월만 남는다. 12개월 학습을 시작으로 6개월 뒤 결과를 18번 비교하려면 거래가 빠짐없이 있어도 최소 35개월의 완결 이력이 필요하다.

5년 자료에서도 감쇠추세가 마지막 가격 유지 방식보다 평균 절대오차를 5% 이상 줄이지 못하면 전망을 모두 보류했다. 보유한 6개 단지의 매매·전세·정확 면적별 109개 공공 시계열을 비교했을 때 기존 통과는 0개였으며, 그중 30개는 가격 유지 방식 자체의 자료량·검증·오차 조건을 충족했다. 이는 보유 표본 결과이며 전체 서울·경기 성능을 의미하지 않는다.

## 개선한 동작

- 최근 거래월 평균 총액과 기준월 포함 최근 3개월의 거래건수 가중 평균·최저·최고 계약금액을 제공한다. 거래 없는 달을 오래된 거래로 채우지 않는다. 신고 진행·부분 수신·오래된 거래는 별도로 표시한다.
- 차트 조회기간과 학습기간을 분리한다. 이미 받은 검증된 최대 5년 이력이 있으면 1년 차트를 보더라도 전망 계산에 재사용한다. 짧은 이력만 있으면 `5년 자료로 전망 확인`으로 기간을 확장한다.
- 추세 방식이 가격 유지 방식보다 과거 평균 절대오차를 5% 이상 줄이고 나머지 기준도 통과하면 추세 전망을 선택한다.
- 추세가 통과하지 못하면 마지막 학습월 가격을 유지하는 방식의 오차와 범위를 별도로 계산한다. 이 방식도 같은 자료량·신선도·검증 사례 기준과 과거 평균 절대백분율오차 20% 이내 조건을 통과해야 표시한다.
- 두 방식 모두 부족하면 미래 숫자를 보류하고 실제 거래가격·부족한 검증 사례 수를 표시한다. 일부 월 미수신과 예시 자료는 미래 전망을 만들지 않는다.

## 날짜·범위·한계

단지는 월 거래 1건 이상, 유효월 12개월 이상, 관측 기간 18개월 이상, 거래 20건 이상, 마지막 학습월이 기준월보다 4개월 이내인 조건을 적용한다. 6개월 뒤 비교는 18번 이상, 각 예측 시차의 참고범위 계산에는 8번 이상이 필요하다. 최근 2개월은 학습에서 제외한다.

목표월은 **마지막 학습 거래월부터 6개월 뒤**다. 예를 들어 2026년 9월에 7월까지 학습했다면 2027년 1월 전망이다. 화면에 학습 기준월과 목표월을 함께 명시한다.

범위는 각 시차의 과거 예상 오차를 로그 비율로 계산한 뒤 유한 표본 보정을 적용한 80% 분위 기준이다. 모델 선택과 범위 산정에 같은 과거 자료를 사용하므로 독립적인 적중률이나 향후 80% 확률을 보장하지 않는다. 가격 유지 방식에 추세 방식의 오차·범위를 재사용하지 않는다.

전망은 3.3㎡당 평균으로 계산한 뒤 선택한 면적을 곱해 총가격으로 환산한다. 실제 가격 카드의 평균은 개별 계약 총액으로 직접 계산한다. 면적 0.1㎡ 묶음의 반올림 차이, 거래별 층·향·수리 상태, 금리·공급·정책 변화는 통제하지 못한다.

계산은 이미 받은 공공 실거래 자료로 브라우저에서 수행한다. 새 예측 API·유료 서비스·통근 API 호출은 필요하지 않다. 이력 확장 시에는 기존 실거래 조회와 캐시를 사용한다.
