## 결과

- 모바일 320×568 / 390×844 / 430×932에서 hero=568/844/932px. 이름28–32px, 날짜21–24px, 한글 시간14–16px. 1440×884에서 본문480px·표지812px. 가로 넘침 없음, 실제 고운바탕/Cormorant 로딩 확인.
- 이름·날짜 아래 사진 대비를 강화하고 표지 아래 반복 안내, 별도 축하 반응, 하단 날짜 반복을 제거했다. 일정과 지도는 예식 안내 내부에 통합했다. 기본 펼침 상태는 4,110px(390px 폭, 모바일 브라우저 스크롤바 포함). 새 실계좌/하객 안내나 메시지가 입력되면 길이는 달라진다.
- Replay 직후 첫 SVG 획 stroke-dashoffset0.8049px, 다음 획1px으로 순차 쓰기를 확인. 스크롤 후 사진matrix scale1.1/translateY68px, 문matrix3d 회전 확인. 효과 끄기에서는 정적 표시. 기기 모션 감소 CSS/JS 지원은 코드 확인이며 실제 OS 설정 전환은 미실행.
- 오디오 자동 재생이 차단된 실제 브라우저에서 blocked → 첫 터치 playing. 이야기 열고 닫아도 audio1개/재생 연속 유지. 직접 끈 뒤 날짜 탭·사진 확대 조작에서도 paused 유지. 오른쪽 위 버튼 top12px. 음량 슬라이더/YouTube 없음.
- 달력6일 토요일, Google 일정URL의 06:30Z/Asia/Seoul·실제주소, ICS CRLF 및 예식일 검증. 지도 앱 외곽선/아이콘·공식 약도 표시, TMAP 안내 열기/닫기, 주소 복사 성공 피드백 확인. 휴대폰 OS별 지도 앱 열기·캘린더 가져오기·실제 은행 앱 붙여넣기는 미실행.
- 사진첩 1개, 02/06 전환·닫기·캡션 없음 확인. 빈 앨범/추가사진 처리는 기존 계약 유지, 6장 초과는 더 보기로 접는다. 로컬 앨범/방명록 GET 성공, 방명록 작성폼은 공개 동의 절차 유지. 운영 DB에는 검증 글이나 사진을 쓰지 않았다.
- 계좌는 실제정보 미입력이라 공개 숨김. 테스트에서는 완성된 계좌만 렌더, HTML 탈출·허용된 송금 URL·연락처 검증·잘못된 URL 거부를 확인했다. 신랑/신부 계좌 복사 버튼은 숫자만 복사하고 완료 피드백/붙여넣기 안내를 제공한다. 실제 번호는 아직 받지 않았다.
- 참석 응답은 실제 외부 HTTPS 폼 연결 준비이며 현재 수집 기능은 미연결/숨김이다. 개인 연락처·주차/식사·간편송금도 실제정보를 받아야 공개된다.
- 전체 1,941개 검사 통과, 760개 로컬 참조·226개 JS 문법 검사 통과. 실제 브라우저 오류/경고0. 초기 제한된 셸의 소켓/임시파일 권한 실패는 정상 권한 환경에서 재실행하여 통과했다.
