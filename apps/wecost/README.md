# WeCost

결혼비용과 저축을 모아 가용현금·집 예산·월 대출 부담을 비교하는 4탭 앱이다. **현재 데이터는 Firebase Firestore**이며 Google Sheets는 사용하지 않는다.

| 탭 | 역할 |
|---|---|
| 대시보드 | 가용현금·집 예산·월 납입·다가오는 지출·목표가 |
| 현금흐름 | 두 사람의 현재 저축·월 저축·예상 저축 |
| 결혼비용 | 항목별 계획·지급·잔금·분류·일정, Travel 신혼여행 세부 예산 연결 |
| 집 시뮬 | 지원금·대출·조정 항목을 포함한 자금 계획 |

소스는 `index.html`, `css/`, `js/`이며 `/sungso/wecost/`로 출력된다. 금융 계산·목표 집값 연결은 `shared/finance/`에서 HomeHunt와 공유한다. 컬렉션과 편집 시 주의할 필드는 [AGENTS.md](AGENTS.md)에 정리했다.

Travel은 기존 `✈️신혼여행` 비용 항목 하나를 연결해 세부 예산과 증감을 보여준다. 양쪽 앱에서 같은 예상액·지급액·잔금을 사용하며, 신혼여행 비용을 새 장부 항목으로 복제하지 않는다. 공통 `travel-budget-core.mjs`·`travel-budget-store.mjs`가 계산·동시 편집 검사·금액 변경 이력을 담당한다.

저장소 루트에서 `npm run dev`를 실행한다. [개발·검증](../../docs/development.md), [과거 백업·참고자료](../../archive/wecost/)를 참고한다. 백업은 현재 앱의 원본으로 덮어쓰지 않는다.
