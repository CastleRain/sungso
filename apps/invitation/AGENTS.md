# Invitation 작업 지침

[루트 지침](../../AGENTS.md)과 [앱 안내](README.md)를 따른다.

- 이 앱은 템플릿 비교·옵션 선택용이다. 실제 제작·하객 공개 기능을 섞지 않는다.
- 공개 경로 `/sungso/invitation/`, hash 화면 계약을 유지하고 공통 Google 인증 후 직접 링크로 복귀한다. 작성자 선택은 인증된 회원 역할을 따른다.
- 앱 전용 JS/CSS/예시 이미지는 이 앱에서 관리한다. 다른 앱의 초기화·여행 결정 패널을 import하지 않는다.
- `couplePicks/invitation_templates`만 사용한다. 조회 시 시딩하지 않는다. 리조트 선택 필드·보안 규칙을 부수적으로 바꾸지 않는다.
- 사람별 찜은 트랜잭션 중첩 병합, 공동 선택은 번호 비교와 명시적 저장을 유지한다. 충돌 확인 자체가 저장이 되어서는 안 된다.
- `sungso-invitation` 앱 인증 동기화 후 연결한다. 찜은 본인 역할만 수정하며 `updatedBy`는 회원 UID, `updatedAt`은 서버 시각이다. 로그아웃 시 구독을 정리하되 `sungso_invitation_v1` 로컬 초안은 보존한다.
- 기기 임시 설정과 공동 선택을 구분한다. 복사·JSON 출력은 공동 저장된 선택만 내보낸다.
- 예시 사진과 정보를 실제 두 사람의 사진·시간·장소로 표현하지 않는다. 실제 연락처·계좌·사진 업로드·참석 답변을 저장하지 않는다.
- 모바일 미리보기 안에 별도의 세로 스크롤 영역을 만들지 않는다. 전체 문서 스크롤과 모션 감소 설정을 존중한다.
- 특별한 디자인의 체험 상태는 `experiences.mjs`·시그니처·이야기 에디션 컨트롤러의 메모리에서만 관리한다. 기존 ID·저장값을 유지하며 장면 상태를 공동 문서·선택서에 포함하지 않는다. native 버튼·키보드·다시 보기·모션 감소를 지원하고 체험 완료로 본문을 잠그지 않는다.
- 검증은 `tests/qa-server.mjs`의 메모리 대역과 localhost Firestore Emulator만 사용한다. QA 서버·테스트·문서·생성 프롬프트는 공개 등록부에 넣지 않는다.
