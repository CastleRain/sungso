# 우리 결혼

하객노트와 준비 메모를 정리하고 기존 결혼·여행 앱으로 연결하는 생활 앱이다. 소스는 `apps/wedding/`, 공개 경로는 `/sungso/wedding/`로 등록한다. [작업 지침](AGENTS.md)과 [생활 앱 계획](../../docs/development-plans/active/couple-life/README.md)을 함께 읽는다.

## 화면과 기록

- **하객노트:** 이름·양측 구분·관계·초대 상태·참석 상태·동반인 포함 인원·메모를 기록한다.
- **준비 메모:** 준비할 일과 메모를 적고 완료를 체크하거나 되돌린다.
- **기존 앱 연결:** 청첩장·결혼비용·리조트 비교·여행 일정·우리 일정의 원래 화면으로 이동한다.

공통 Google 회원 확인 뒤 화면을 연다. 신규 하객·준비 기록은 **현재 브라우저의 현재 계정에만 저장**하며, 다른 기기나 상대 계정과 자동 공유하지 않는다. 기존 앱에서 관리하는 공동 선택·비용·일정을 이 앱으로 복제하거나 변경하지 않는다.

하객 정보는 일반 텍스트로 다룬다. 연락처·축의금·자동 메시지 전송·하객 공개 응답 페이지는 현재 범위에 포함하지 않는다. 초대 상태를 변경해도 초대장이 전송되지 않는다.

## 구성과 검증

`index.html`은 개인 내용을 포함하지 않는 숨긴 루트와 공통 인증 진입점을 둔다. `js/entry.mjs`가 앱의 `definition.mjs`를 공통 `shared/life/ui.mjs`에 전달한다. 실제 저장·검증은 `shared/life/`에서 담당한다.

루트에서 `npm run build`, `npm test`, `npm run check`를 실행한다. 생성된 `/sungso/wedding/`을 운영 연결 차단 대역에서 1440px·390px으로 확인하고, 하객 상태·인원·준비 완료·수정/삭제·저장 실패·재방문·계정 변경과 기존 앱의 링크를 검증한다. 실제 하객 이름이나 운영 기록을 QA에 사용하지 않는다. 실행 결과는 통합 검증 기록에 남기며 이 문서만으로 브라우저 검증이나 원격 배포를 완료 처리하지 않는다.
