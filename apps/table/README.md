# 우리 식탁

장보기·뭐 먹지·둘만의 레시피를 담는 생활 앱이다. 소스는 `apps/table/`, 공개 경로는 `/sungso/table/`로 등록한다. [작업 지침](AGENTS.md)과 [생활 앱 계획](../../docs/development-plans/active/couple-life/README.md)을 함께 읽는다.

## 화면과 기록

- **장보기:** 품목·수량·단위·분류·메모를 적고 구매 완료를 체크하거나 되돌린다.
- **뭐 먹지:** 저장한 레시피와 우리 발자국의 식당·카페를 후보로 살펴본다. 방문 장소를 별도로 복제하지 않는다.
- **둘만의 레시피:** 요리 이름·줄별 재료·만드는 순서·우리의 팁을 기록한다. 필요한 재료를 명시적으로 장보기에 추가한다.

공통 Google 회원 확인 뒤 화면을 연다. 생활 기록은 **현재 브라우저의 현재 계정에만 저장**하며, 다른 기기나 상대 계정과 자동 공유하지 않는다. 기존 Firebase 문서나 결혼비용을 변경하지 않는다. 사진 업로드·가격 수집·주문 기능은 없다.

처음에는 빈 목록을 보여준다. 입력 칸의 예시는 설명이며 저장되는 샘플이 아니다. 레시피에서 추가한 장보기는 추가 당시의 재료를 보존하고, 이후 레시피를 고쳐도 임의로 바뀌지 않는다.

## 구성과 검증

`index.html`은 개인 내용을 포함하지 않는 숨긴 루트와 공통 인증 진입점을 둔다. `js/entry.mjs`가 앱의 `definition.mjs`를 공통 `shared/life/ui.mjs`에 전달한다. 실제 저장·검증과 교차 앱 연결은 `shared/life/`에서 담당한다.

루트에서 `npm run build`, `npm test`, `npm run check`를 실행한다. 생성된 `/sungso/table/`을 운영 연결 차단 대역에서 1440px·390px으로 확인하고, 장보기·레시피 저장/수정/삭제·재방문·계정 변경·우리 발자국 연결을 검증한다. 실행 결과는 통합 검증 기록에 남기며 이 문서만으로 브라우저 검증이나 원격 배포를 완료 처리하지 않는다.
