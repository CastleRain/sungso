# 소희 공간 지침

루트 AGENTS.md와 README.md를 따른다. 기존 공동 앱을 대체하지 않는다.

- 현재 `prototype/`은 독립 로컬 미리보기이고 config/apps.json에 등록하지 않는다.
- `prototype/`은 둘 모두 편집할 미래 공간의 예시이며 개인 데이터를 직접 연결하지 않는다. 사용자 요청의 `sales/`는 공통 회원 인증·Firestore 조회와 별도 원본 갱신 서비스를 사용한다.
- 실제 프로젝트가 아직 없으므로 작업실은 빈 상태다. 포트폴리오 구성 예시를 실제 경력·실적으로 기록하지 않는다.
- Sheets·사진 업로드·AI 추천·PDF·배포는 요청 전까지 범위를 확대하지 않는다.
- 선택된 대문 시안은 오른쪽 ‘우리의 작업실’ 영역이다. 포트폴리오는 사용자 요청에 따라 첫 시안을 임시 예시로 구현했으며 최종 디자인 선택으로 간주하지 않는다.
- 기존 공통 테마 토큰을 직접 import한다. 새 색상을 하드코딩하지 않는다.
- 정식 통합 시 공통 회원 인증 이후 개인 영역을 표시하고 기존 저장 계약을 보존한다. 프로토타입의 무인증 예시 화면을 실제 개인 기록에 재사용하지 않는다.

- 2026-09-27: 소희 작업실에서 별도 다섯 경로의 매출 앱으로 연결한다. 통합 로컬 미리보기는 `sales/preview.mjs`다. 운영 데이터 이전·규칙/Pages 배포·토스 자동 수집은 별도이며 가상 QA와 실제 매출을 구분한다.

- 2026-09-27: 사용자 연결 요청으로 `workspace/`에 회원 진입점을 만들고 기존 구성 요소를 재사용한다. `build.mjs`가 생성한 코드 전용 `dist/`만 등록부에 포함한다. `prototype/`의 독립 시안·Sites 파일과 가상 표시를 보존한다.
