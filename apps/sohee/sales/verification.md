## 해석·공개 경계

- 사용자가 화면에서 별도로 확인한 최신 합계는 상세 거래에 반영하지 않았다. 새 원본이 필요한 상태를 유지한다.

## 미검증·후속

1. 실제 계정의 운영 Firebase 조회·저장, 두 기기 동기화, 운영 규칙 배포는 아직 수행하지 않았다. 기본 서버 모드는 쓰기를 잠근다.
2. 갱신 버튼은 **새 토스 ZIP 검증·저장**이다. 사용자의 후속 선택에 따라 로컬 토스 화면에서 수동으로 받는다. 자동 API 수집은 추진하지 않는다. [수동 갱신 절차](../../../services/sohee/manual-update.md)를 따른다.
3. 서버·원본은 한 PC의 비공개 영구 폴더를 전제로 한다. 공개 서비스에는 HTTPS 실행 위치·지속 보관·접근 주소 결정이 필요하다. Render Free 임시 디스크만으로 원본을 운영하지 않는다.
4. 브라우저에서 실제 개인 원본 업로드·회원 계정 전환·인쇄 미리보기·실물 모바일 기기·다른 브라우저는 미검증이다. 업로드 및 정리 동작은 합성 컴포넌트/서버/Emulator 검사와 구분한다.
5. 실제 사장님의 사용성 평가와 이후 당일 판매·폐기 기록을 통한 준비량 재평가는 남아 있다. 화면의 초안을 확정 생산량으로 사용하지 않는다.
