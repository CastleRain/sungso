# 우리 발자국

식당·카페·데이트 장소와 방문 기록, 외부 사진 앨범을 연결하는 생활 앱이다. 소스는 `apps/footprints/`, 공개 경로는 `/sungso/footprints/`로 등록한다. [작업 지침](AGENTS.md)과 [생활 앱 계획](../../docs/development-plans/active/couple-life/README.md)을 함께 읽는다.

## 화면과 기록

- **우리의 장소:** 이름·지역·종류·주소·지도 링크·가고 싶음·메모를 기록한다.
- **방문 · 데이트:** 저장한 장소를 고르고 방문 날짜·이야기를 남긴다. 같은 장소의 여러 방문을 각각 기록한다.
- **사진첩:** 앨범 이름·보기 링크·메모를 담고 선택적으로 방문 기록과 연결한다. 사진은 원래 보관한 서비스에서 연다.

공통 Google 회원 확인 뒤 화면을 연다. 생활 기록은 **현재 브라우저의 현재 계정에만 저장**하며, 다른 기기나 상대 계정과 자동 공유하지 않는다. 장소를 하나 저장하면 우리 식탁의 외식 후보도 같은 장소를 사용한다.

지도 링크 열기는 NAVER 즐겨찾기 자동 가져오기나 동기화 기능이 아니다. 사진첩은 앨범 링크 모음이며, 사진 원본 업로드·자동 갤러리·사진 서비스 권한 확인은 구현 범위에 포함하지 않는다. 외부 앨범의 공유 범위는 사진 서비스에서 별도로 관리한다. 링크를 삭제해도 외부 원본을 삭제하지 않는다.

## 구성과 검증

`index.html`은 개인 내용을 포함하지 않는 숨긴 루트와 공통 인증 진입점을 둔다. `js/entry.mjs`가 앱의 `definition.mjs`를 공통 `shared/life/ui.mjs`에 전달한다. 실제 저장·검증과 교차 앱 연결은 `shared/life/`에서 담당한다.

루트에서 `npm run build`, `npm test`, `npm run check`를 실행한다. 생성된 `/sungso/footprints/`을 운영 연결 차단 대역에서 1440px·390px으로 확인하고, 장소·여러 방문·앨범 연결·저장 실패·재방문·계정 변경과 우리 식탁 연결을 검증한다. 지도·사진 공급자에 테스트 요청을 보내거나 개인 사진을 QA 자료로 사용하지 않는다. 실행 결과는 통합 검증 기록에 남기며 이 문서만으로 브라우저 검증이나 원격 배포를 완료 처리하지 않는다.
