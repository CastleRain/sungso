# HomeHunt Ver2 실제 자료 실험 보고서

확인일: 2026-10-11. 월말 예측의 마지막 완결 기준시점은 **2026-09-30**, 목표월은 **2027-03**이다. 10월말에 알 수 있는 자료를 10월11일에 이미 알고 있다고 취급하지 않는다.

현재 결론은 **새 방향 모델을 매수 판단용 확률로 공개하기에는 성능이 부족하다**이다. 실제 가격과 내 조건의 비교는 제공하지만 상승·보합·하락 확률은 모두 `null`로 보류한다. 자료와 실험 결과는 공개 JSON에서 확인할 수 있다.

현행 연구 소스는 `services/homehunt/research/v2/`, 공개 JSON은 `apps/homehunt-v2/data/`다. 기존 실행의 대용량 원자료·캐시는 원래 Git 제외 로컬 위치에 보존하고 명시적 입력 경로로 재사용한다. 공개 JSON 7개를 원본 SHA-256과 대조해 이식한 뒤, 독립 감사에서 모델 선택용 목표값의 확정 시점 결함을 발견하여 **direction-6m-1.1.0**으로 보유 자료만 재실험했다. 원래 결과는 보존했고 추가 HTTP/API 호출은 없었다. 새 로컬 실행의 비공개 저장소는 `services/homehunt/.local/research/v2/`다.

## 1. 실제 확보한 자료

기존 HomeHunt의 국토부 공개 월 캐시를 재사용하고, 사용자가 지정한 지역에 대해 120개월 범위를 설정한 뒤 실제 호출 예산 안에서 최근부터 과거로 수집했다. 기존 비밀키를 읽어 사용했으며 키·요청 URL·개인 회사·WeCost 원장은 연구 자료나 로그에 포함하지 않았다. 통근 API는 호출하지 않았다.

영통구의2026-10은 기존 캐시에서 추가 확인한 신고 진행월이며,9월말 실험이나 현재 가격 기준에는 사용하지 않는다. 확보 범위는 월 파일의 존재와 응답 완전성을 의미하며, 단지별 거래가 매달 존재한다는 뜻이 아니다. 지정 5개 동네의 분석 표본과, 해당 시군구 전체에서 볼 수 있는 실제 가격 후보를 구분한다.

기존 서울·수원·안양 등의 5년 월 자료와 합쳐 **1,478개 지역·월·거래유형 파일**에서 단지 대조가 된 매매·전세 **441,867건**을 활용했다. 원본 대조 미확인 27,178건, 월세 보증금 175,439건, 새 원문에서 확인한 취소 7,314건은 매매·전세 가격 시계열에서 제외했다. 기존 normalized cache에서 이미 제거된 취소 거래는 재계산할 수 없다.

국토부 외부 HTTP 요청은 초기 연결·구코드 대조와 중단된 배치를 포함해 **최대 약480회** 범위에서 수행했다. 마지막 재개 배치는 실제296회·정상269월·캐시158회 재사용이었고, 120개월 전체를 확보했다는 주장은 하지 않는다. 원 XML과 실행별 체크포인트·내용 해시는 Git 제외 `.local/research/`에 보존한다. 신규 collector의 기본 한도는24회다.

화성은 중요한 코드 변경이 있었다. 기존 REB 카탈로그는41590을 사용하지만, 실제 국토부의 새41597 조회는2024-01에도292건, 2025-01에도259건을 반환했다. 구41590은 해당 기간에 정상0건이었다. 따라서 과거월을 구41590으로만 조회하면 동탄의 거래가 없는 것으로 오인할 수 있다. 새 구 코드와 구 카탈로그를 연결할 때도 법정동·단지명·필요시 지번을 대조한다. ## 2. 당시 자료 검증 수준

이번 결과는 모두 **과거 재구성 실험(reconstructed)**이다. API의 최신 과거 자료는 신고·취소·정정 이후의 상태이며 당시 어떤 날짜에 공개되었는지 증명하지 못한다. 관측월+2개월의 보수적 지연을 적용했다고 해서 당시 공개자료 검증(strict)이 되는 것은 아니다.

새 수집은 취소 필드와 원 XML을 보존한다. 앞으로 당시 스냅샷·특징·예측을 누적하면 향후 전향 검증이 가능하다. 과거 공표일·개통일·규제 효력일이 불명확한 특징은 엄격 검증에서 제외한다. 수집일을 과거 공표일로 대체하지 않는다.

기준금리 이력은 공식 변경일 자료를 재사용했다. 은행 주담대 평균은 확보된 이력이짧고 최종시험 이전의 학습에30개 유효 관측이 없어 Model B에서 제외했다. 현재 역 좌표는 과거 개통·환승·실제 도보 경로의 이력이 없어 Model C의 교통변수로 사용하지 않았다. 세대수는 현재 카탈로그 값을 과거에도 같다고 가정한 정적 대리변수이며 변동 이력을 확보하지 못했다. `strict=True`에서는 당시 공표가 검증된 관측만 사용하고 없으면 결측으로 둔다.

## 3. 대상과 워크포워드

공식 카탈로그의 연식·규모 층을 기준으로 **60개 단지**를 먼저 선정했다. 현재 가격이나 나중의 예측 성능으로 표본을 고르지 않았다. 가격 학습 기준을 충족한 단지는35곳이며 나머지는 신축·임대·명칭 대조·희소 거래 등의 이유로 보류한다. `analysis-targets.json`에 선정 방법과 포함/보류 상태가 있다.

실제 전용면적의 소수값을 보존해 서로 다른 면적을 합치지 않았다. 월별 학습 표본은 **1,194개**다. 기준가격은 예측월의2개월 전을 마지막 거래월로 하는 최근3개월 평균이며 최소3거래가 필요하다. 최근12개월 중 거래월이6개월 미만이거나12개월 비교 가격이 부족하면 제외한다. 가격이 없는 달을0원이나 미래가격으로 채우지 않는다.

예를 들어2026-09월말 예측의 기준가격은2026-05~07 거래 평균이고, 목표는2027-03월말까지의 최근3개월 가격 평균이다. 기준 거래월과 예측 기준월·목표월은 별도 표시한다. 목표 자료의2개월 신고 지연까지 지나야 학습에 들어가므로 훈련 origin과 다음 예측 origin 사이에최소8개월의 간격이 생긴다.

최종 시험은 **2024-02~2026-01의24개 origin**, 모델 선택용 개발 구간은 **2023-02~05**다. 이 개발 목표값은6개월 후 목표와2개월 신고 지연을 거쳐 늦어도2024-01에 확정되므로 첫 시험2024-02 이전에 알 수 있다. `selectionAudit`의 선택 cutoff는2024-01, 마지막 개발 목표확정월도2024-01이다. 개발 평가 표본은11개(상승9·보합2·하락0)로 매우 적다. 선형·트리 후보와 A~C 중 선택은 이 개발 구간에서만 수행했다. 전처리·결측값 보정·확률 온도 보정도 각 시점에서 이미 확정된 과거 훈련 사례 안에서만 학습했다. 전체 미래 panel에만 존재하는 특징을 과거 사용 가능 변수로 선정하지 않는다.

기본 방향 구분은±3%이고±2%·±5%는 별도 재학습한 민감도 실험이다. 마지막 시험의 적중률이 가장 높은 임계값으로 기본 기준을 교체하지 않았다.

시험 자료의 실제 방향은 **상승340·보합120·하락19개**다. 항상 상승이라고 해도71%가 맞으므로 적중률만으로 좋은 모델이라고 할 수 없다. 실제 하락 표본이19개밖에 없어 하락 방어력에 대한 결론도 제한된다. 클래스별 Precision/Recall/F1·혼동행렬은 `backtest.json`에 있다.

수정된 개발 구간에서는 A~C·선형/트리 모두 Macro F1이0으로 동률이다. 따라서 고정된 기본 순서의 **A·선형**을 참고 후보로 두었을 뿐, 좋은 모델이 발견된 것은 아니다. 최종 시험의 Macro F1·변동률 오차·지역 제외 검증·하락 표본 기준도 통과하지 못했다. 가장 강한 단순 기준 대비 개선의95% 참고범위도0을 포함한다. 표본의 상관을 고려하기 위해 지역 묶음을 재표집하고 동일한6개월 연속 월 묶음을 모델·기준에 함께 적용했다. **A는 실험의 기본 참고 후보이며 운영 승인 모델이 아니다.**

D는 전세·공급 특징을 검토했지만 정확면적 매매/전세가 연결된 최종시험 이전 훈련 자료가30개 기준에 미달했다. 미분양·입주 예정 이력도 미확보여서 이번 최종 실험에서는 `unavailable`이다. E는 허용된 무료 장기 경매 자료를 확보하지 못해 `unavailable`이다. 이들이 성능을 개선했다고 표현하지 않는다.

이전 탐색 실험에서 전체 기간의 자료 확보 여부로 D 변수를 선정했던 결과는 폐기했다. 또한2023-10~2024-01 개발 결과는 첫 시험2024-02 시점에 목표값이 확정되지 않았으므로 그 구간으로 B를 선택한 이전 결과도 폐기했다. 최종 공개 값은 시험 이전 훈련 자료로 변수 확보 여부를 고정하고 당시 이미 확정된 개발 목표값만 사용해 다시 계산한 결과다. 이번에는 A~C가 모두 같은 선형 추정기를 선택하여 공통 시험479개 자체의 수치는 같지만 모델 선택·개발 성능·제외 검증은 수정됐다.

미관측 지역12개·단지28개에 대한 제외 검증도 제공한다. 지역 제외는24개 시험 origin, 단지 제외는 계산 범위를 명시한 마지막6개 origin이다. 변수 추가 효과는 단계별 공통 표본 비교로 설명한다. 새로운 특징이 원인이라고 주장하지 않는다. 최초 하락장 시작보다 경고가 몇 개월 먼저였는지는 이 희소 표본에서 확립하지 못했으며,6개월 예측 horizon을 관측된 선행기간으로 표시하지 않는다.

## 5. 현재 집 탐색에 제공하는 내용

모델 선정60단지와 별도로 보유 공공자료 전체를 집계한 `market-prices.json`에는2026-05~07의 최소3거래 실제평균을 가진 **3,116개 단지·정확면적 조합 / 1,939개 단지**가 있다.

5집중시군구 안에서 **전용59㎡이상·평균7억원 이하**인 조합은636개, 중복을 제거한 단지는359곳이다. 이는 지정 동네 전체에 그만큼의 매물이 판매 중이라는 뜻이 아니다. 같은 단지가 여러 면적을 가지므로 조합 수와 단지 수를 분리하며, 목적지·주차·세대수·연식 등은 Ver2의 실제 조건에서 다시 판정한다.

가격 매력도는 같은 시군구·면적±10%·준공±5년의비교 단지5곳 이상이 있을 때㎡당실거래 분포의 상대적 위치로 표시한다. 현재1,424개 조합에 계산 가능하다. 미래 수익률·최적 추천 점수·저평가의 증명으로 해석하지 않는다. 층·동·미세 입지는 아직 보정하지 않았고 출처·비교 표본 수를 함께 둔다.

학습 가능한 최근 면적47개에 대해 기준가격·표본·품질 근거를 제공하되 방향 확률·예상변동률은 전부보류한다. 최근가격 자료의 실확인일이30일을 넘거나 현재 fit에 과거 시점 확률 보정 자료가 없으면, 과거 모델 검증 기준을 통과하더라도 해당 현재 수치는 공개하지 않는다.

따라서 이번 버전에서는 가격·통근·자금·생활 조건에 맞는 **검토 후보를 찾고 실제가격을 비교하는 기능**을 사용할 수 있다. `매수/협상/대기`를 예측 확률로 단정할 자료는 아직 부족하다.

## 6. 갱신·검증·다음 자료

모델·publisher Python 회귀검사28개를 통과했다. 실제 면적 분리, 동명 단지, 늦은 공표, 개통 전 노선, 미래 목표의 학습 차단, **첫 시험 이전 모델 선택용 목표확정**, **strict 세대수 관측**, 희소가격,현재 확률 보정 누락, 마지막 검증 전망 보존, 확률합과6개월 목표 계약 및 월별 실험 자체 승인 상태를 검증했다. 별도 월 갱신 오케스트레이터의 subprocess 대역 검사12개를 더해 연구 검사 전체40개도 통과했다. 재현 환경은 pandas 2.3.3·NumPy 2.2.6·scikit-learn 1.7.2로 고정했고, 배포 CI에서도 API 호출 없이 이 검사를 실행한다.

분석은 staging에서 완료한 후 파일 publisher가 반영한다. 실패한 학습은 public 파일을 수정하지 않고, 새 성능 gate 실패는 마지막 검증된 전망을 보존한다. 새 실험의 검증표·자료 현황·실제가격과 `update-status.json`은 별도로 갱신해 보존 중인 전망의 원 기준월·목표월을 명시한다. 현재는 과거 검증 전망 자체가 없어서 `tested_withheld` 상태다.

`refresh.py`는 기본적으로 직전 완결월·지정5지역·최근2개월·HTTP24회 상한의 읽기 전용 계획만 출력한다. `--execute`를 명시하면 최근2~3개월만 갱신하고 보유 장기 자료로 비공개 후보에서 학습한 뒤 성공한 결과를 반영한다. 빈 표본·수집/학습 실패는 기존 공개 결과를 보존하며 실제 자동 스케줄은 설정하지 않았다. 이 오케스트레이터 추가에서는 대역 검사와 계획 출력만 실행했고 추가 실제 API·학습 호출은0회였다.

다음 우선순위는 집중지역의 장기 전세 **정확면적** 연결, 당시 입주계획·미분양과지역지수의 공표 이력, 역사적 개통·환승·접근성과 대출규제, 향후 불변 스냅샷 축적이다. 층·거래구성 보정, 이상 거래 제외 전후 비교, 변수별 선행시차는 이 입력을 확보한 뒤 독립 실험으로 진행한다. 현재의 낮은 성능에 맞춰 시험 구간을 바꾸거나 미래 자료를 추가하지 않는다.
