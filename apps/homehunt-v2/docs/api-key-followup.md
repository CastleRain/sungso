# Ver2 추가 API 신청 안내

확인일: 2026-10-11. **아래 세 키는 후속 연구용 후보이며 현재 발급을 기다리는 동안 사이트를 막지 않는다.** 현재 자동 수집 어댑터에 연결되었다는 뜻은 아니다. 발급 후 소량 실응답·공표일·지역 범위를 확인하고 수집기를 연결한다. 그 전에는 공식 파일/CSV 가져오기를 사용한다.

| 우선순위 | 제안 환경변수 | 자료와 목적 |
|---|---|---|
| 1 | `RONE_API_KEY` | 한국부동산원 지역 가격·전세 지수와 거래 통계, 단지 희소 거래의 지역 참고 |
| 2 | `ECOS_API_KEY` | 한국은행 장기 주담대 금리·금융 이력, 현재의 짧은 금리 이력 보강 |
| 3 | `KOSIS_API_KEY` | 인구·가구·일자리 등 공식 지역 통계, 공표 시점에 맞춘 지역 변화 |

## 신청

**R-ONE:** [공식 개발가이드](https://www.reb.or.kr/r-one/portal/openapi/openApiDevPage.do)에서 로그인 → Open API 목록에서 필요한 통계 확인 → 인증키 발급 메뉴에서 신청한다. 사용할 API 명세를 함께 확인한다. 국토부 공공데이터 키와 별도이며 sample 응답은 전체 이력의 대체 자료가 아니다.

**ECOS:** [한국은행 Open API](https://ecos.bok.or.kr/api/)의 인증키 신청에서 안내에 따라 신청한다. 서비스 설명은 `개인 아파트 매수 검토를 위한 공식 금리·지역시장 분석, 비상업적 연구`로 적을 수 있다. [한국은행 공식 이용 안내](https://www.bok.or.kr/portal/bbs/B0000522/view.do?menuNo=201692&nttId=10070977)는 키 발급 후 명세에 따라 활용하는 절차를 설명한다. 승인/발급 시간은 해당 화면의 안내를 따른다.

**KOSIS:** [공유서비스](https://kosis.kr/openapi/) 로그인 → 활용신청/OPEN API 인증키 신청 → 신청현황에서 인증키를 확인한다. 기존 KOSIS 계정을 사용할 수 있으며 회원당 하나의 키로 서비스를 이용한다. [공식 FAQ](https://kosis.kr/openapi/community/community_0401List.do)의 이용·출처·유효기간을 확인한다.

## 키를 받은 뒤

서비스의 비공개 `services/homehunt/.env`에 발급값을 넣고 **어느 공급자를 신청했는지만** 알려준다. 예전 작업 폴더의 `homehunt/.env`는 그대로 두며 키를 채팅·캡처·Git에 올리지 않는다. Render/GitHub 수집 연결은 기존 비밀 설정을 보존한 별도 서버 설정 단계다.

현재 실거래·분양·시설은 기존 `MOLIT_SERVICE_KEY`를 재사용하되 각 API 활용승인이 필요하다. TMAP 추가 키 발급으로 일일 제한을 우회하지 않는다. 매물/호가·장기 경매·당시 입주계획은 위 세 키만으로 확보된다고 보장하지 않는다. 허용 자료가 없으면 계속 미확보로 표시한다.
