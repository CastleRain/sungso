# Ver2 구현 검증 · 2026-10-11

## 통과한 검사

- 최신 master의 앱·공통·서비스 구조를 기준으로 기존 25개 로컬 커밋을 일괄 덮어쓰지 않고 통합했다. 원래 작업 폴더의 환경변수·원자료·캐시·통근 장부와 관련 없는 수정은 보존했다.
- Node 22 공개 빌드·참조·전체 회귀 검사 1,872개, 실제 브라우저 파서 187개 공개 JS 모듈, Render/Firebase 세 서비스 번들, 기존 소희 앱의 컴포넌트/비공개 경계 검사가 통과했다.
- 별도 localhost Firestore Emulator의 회원·본인 UID·revision·서버 캐시 권한 검사 57개와 Python 연구 검사 40개가 통과했다. 운영 Firebase 데이터를 초기화하거나 검사용 기록을 쓰지 않았다.
- 생성된 `/sungso/` 사이트의 격리 SDK 대역에서 8개 메뉴, 1440px·390px·430px 배치, 접힌 지도 조건, 한국어 금액 입력, 후보 수 변화, 검색 실패/취소 시 이전 가격 유지, 계정 전환과 명시 복원 흐름을 확인했다.
- 대역 계정 A의 관심 기록은 B에서 표시/수정되지 않았다. B의 명시 복원 전 원본을 로컬 복구 사본으로 보존한다. 복원한 B 방문 기록을 Ver1의 내 기록에서도 읽었다. V2 조건은 UID별·버전별로 분리되고 원래 V1 조건을 자동 변경하지 않는다.
- 공개 JSON 7개에 개인 UID·회사·재무·비밀키가 없는지 확인했다. 공개 등록부는 앱 자산만 포함하며 연구 코드·원자료·캐시·`.env`·테스트/문서를 배포하지 않는다.

## 실제 자료와 대역의 구분

보유한 공식 실거래 441,867건으로 실제 워크포워드 실험을 수행했다. 공통 최종 시험은 479사례다. 최근 실제 가격 관측은 3,116개 단지·정확면적 조합/1,939개 단지이며, 기준 창은 2026-05~07이다. 현재 판매 중인 매물·오늘 가격으로 표현하지 않는다. 공공자료의 원수집일·부분 조회를 유지한다.

방향 모델은 승인 기준을 넘지 못했다. 현재 47개 전망의 상승/보합/하락 확률과 예상 변동률은 모두 `null`이다. Model D/E의 미확보 전세·공급·경매를 임의 생성하지 않았다. 현재 카탈로그 세대수를 과거 고정값으로 사용한 재구성의 한계와 strict 자료 부족을 표시한다.

화면 검증의 회원/지도/검색 실패는 격리 대역을 사용했다. 실제 Google 회원의 개인 기록을 변경하거나 새 실제 통근을 호출한 검사가 아니다. 네이버 지도의 실제 인증·좌표 조회, 회사별 실제 경로, 회원의 온라인 가격 작업 및 WeCost 목표값은 운영 로그인 후 추가 읽기 검증 대상으로 남는다. 자동으로 실제 통근을 조회하거나 Telegram을 발송하지 않는다.

## 운영과 남은 작업

- Ver1/Ver2는 동일 검색 서버·공급자 호출 장부를 사용한다. 로컬 통근 원호출 0회 정책과 TMAP 일일 제한을 유지했다.
- 연구는 별도 Python CLI다. 월 갱신은 기본 dry-run, `--execute` 때만 제한된 국토부 수집/학습을 실행한다. 월별 자동 스케줄은 아직 설정하지 않았다.
- 새 실험 실패 시 마지막 검증 전망을 유지하며 운영 기준월과 최신 실험 기준월을 별도로 표시한다. 동일 프로그램 버전의 다른 월을 같은 학습 결과로 간주하지 않는다.
- 추가 R-ONE·ECOS·KOSIS 키는 아직 자동 수집 어댑터에 연결되지 않았다. 발급과 서비스 연동/장기 이력 확보를 구분한다. 자세한 신청 방법은 [API 안내](api-key-followup.md)를 따른다.
- 공개 배포 실행 번호·웹 산출물 대조 및 검색 서버 상태는 루트 `AGENTS.md`의 최종 진행 상황을 따른다. 이 문서만으로 원격 배포나 실제 회원 API 검증을 완료했다고 간주하지 않는다.

**다음:** 운영 로그인 후 기록을 바꾸지 않는 단지 조회를 확인하고, 공표일이 있는 장기 금리·지역지수·공급 이력을 확보해 새 개발 실험을 비교한다.
