# HomeHunt Ver2 작업 지침

루트 `AGENTS.md`, `apps/homehunt/AGENTS.md`, `services/homehunt/AGENTS.md`를 따른다.

- Ver1의 URL·기능·저장 키를 변경하지 않는다. Ver2 조건은 독립적으로 저장하며 공유 기록만 같은 계약으로 연결한다.
- `shared/firebase/boot.mjs` 회원 확인 후만 실행한다. 계정 전환은 요청·지도·리스너·개인 DOM을 정리하고 로컬 초안은 유지한다.
- 밝은 UI와 커스텀 컨트롤을 사용한다. 일반 색·폰트는 `shared/theme/brand.css`의 공통 토큰이다. 기본 버튼/선택/확인/날짜 UI를 노출하지 않는다.
- 가격·면적·거래월·건수·실제/미확인/부분/신고 진행 상태를 표시한다. 현재 매물 근거가 없으면 최근 실거래 기준 후보로만 표현한다.
- 임의 합산 추천 점수를 만들지 않는다. 생활·자금·가격 매력·가격 전망은 독립 축이다. 통근은 실제 회사별 검증이 없는 후보를 통과로 처리하지 않는다.
- 자동 통근 원호출 금지. Ver1과 동일 API·공급자 장부, 로컬 0회 정책을 유지한다. API 키는 서비스 환경에만 두고 앱/문서/JSON에 쓰지 않는다.
- 연구는 별도 Python 작업이다. 실제 정확 면적별 시계열을 유지하고 모든 특징·목표·전처리·보정의 공개 가능 시점을 지킨다.
- 최종 시험 구간을 튜닝에 재사용하지 않는다. 미확보 자료는 0/합격으로 채우지 않는다. 운영 승인 실패 시 확률을 보류하고 마지막 검증 모델을 유지한다.
- 자료·모델 JSON은 출처·기준월·목표월·모델 버전·표본·한계를 포함한다. 공개 파일에 회사·UID·재무·개인 기록을 포함하지 않는다.
- 공통 저장 충돌/계정 전환/취소/부분 응답, 1440px·390px·430px UI와 배포 경계를 검사한다. 실제 회원 API 및 실제 경로 검증 여부는 대역 검사와 분리해서 기록한다.

## 진행 상황

### 2026-11-03 — 네 판단 축을 앞에 둔 밝은 글래스 보드

- 선택한 HomeHunt VER2 시안을 확인하고 `css/glass.css`를 추가했다. 글래스에서만 기본 사이드바를 공통 셸로 넘기고 검색·계정 연결/백업·방문 기록 추가를 유지한다. 기존 네 판단 축 설명을 보드 위로 배치하고 조건·후보·자금·지역·확인 항목을 유리 카드로 정돈한다.
- 기본 모드의 DOM 순서와 스타일은 유지한다. JS는 기존 네 축 article의 표시용 클래스 추가만 변경했다. 판단 점수·진행률·미확보 전망을 만들지 않으며 8개 뷰, 조건/기록의 분리 저장, 비교·백업·API·권한·계산 계약을 보존한다.
- 기존 Ver2 검사 20개 및 JS 구문 검사가 통과했다. 브라우저 시각·모드 전환·모바일 검증은 공통 셸 통합 후 진행 대상으로 남아 있다. 운영 DB나 공급자 호출은 하지 않았다.
- 후속 1440px 캡처에서 좁은 지역 5열의 9px 설명을 확인해 글래스 지역 카드를 기본 3열·12px 설명으로 바꾸고 좁은 화면의 기존 2열은 유지했다. 320px에서 넘칠 수 있는 자금 카드 버튼 행과 모바일 카드 제목 행은 줄바꿈하도록 보완했다. CSS 구문 경고 0건, 기존 핵심/배포 경계 검사 15개 통과이며 화면 재확인은 통합 QA에서 진행한다.

**다음:** 합성 QA의 보드·찾기·기록·조건/방문 편집을 1440px/390px에서 두 모드로 대조한다.

2026-10-11: 두 버전 운영을 위한 별도 화면·공유 기록/독립 조건·공식 실제 가격·워크포워드 실험을 최신 구조에 통합·배포했다. 이번 방향 모델은 기준 모델을 충분히 개선하지 못해 운영 확률을 보류한다. Node 22 검사1,872개·Emulator57개·Python40개와 공개23파일 대조가 통과했다. 실제 회원/공급자 조회와 대역 확인의 구분 및 배포 실행번호는 루트 진행 상황을 따른다.

**다음:** 추가 공식 이력의 확보와 당시 공개 스냅샷을 누적해 모델 개선을 다시 평가한다.

- 루트 통합 브라우저 확인: 합성 1440/390/320px 가로 넘침 없음, 8개 업무·보조 메뉴 왕복, 기존 검색/조건 입력의 기본·글래스 전환 보존, 방문 기록 입력/취소를 점검했다. 탐색은 명시적인 예시 클라우드 복원 뒤 방문 목록 표시까지 확인했다. 지도는 공급자 호출을 차단한 대역으로 배치만 확인했으며 실제 위치·경로 정확도 검증은 포함하지 않는다.
