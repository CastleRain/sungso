# HomeHunt Ver2

매수 판단 보드에서 내 조건·실제 가격·여러 회사 통근·자금 부담을 나란히 확인하는 별도 버전이다. `/sungso/homehunt-v2/`로 들어가며 기존 `/sungso/homehunt/`는 그대로 유지한다.

## 사용 흐름

1. 승인된 Google 회원으로 로그인한다. 판단 보드에서 예산과 전용면적을 확인한다.
2. 집 찾기의 접힌 조건을 열어 예산·규모·연식·지역을 적용한다. 실제 가격 관측 후보와 최신 서버 조회를 구분한다.
3. 회사·학교 등 목적지를 최대 네 곳까지 검색해 정확한 건물을 선택한다. 이동시간은 필요한 후보만 명시적으로 확인한다.
4. 지도 숫자 묶음과 목록을 함께 보며 관심·방문 기록에 저장한다. 실거래는 단지와 실제 전용면적을 선택한다.
5. 네 축인 생활 적합도·자금 부담·가격 매력도·가격 전망을 별도로 비교한다. 분양은 공식 공고·가격·접수일과 신청 링크를 확인한다.

현재 자료는 실제 판매 중인 매물 목록이 아니다. `최근 실거래 기준 예산권`과 `판매 중 확인`을 혼동하지 않는다. 3개월 거래가 적거나 오래되면 판정을 보류한다. 가격 방향 확률도 백테스트 승인 기준을 통과하기 전에는 숫자를 표시하지 않는다.

## 저장과 보호

- 방문·관심·분양 관심·개인 주차 관측은 Ver1과 같은 저장 계약을 사용한다.
- Ver2 조건·목적지·비교·화면 상태는 별도 키다. Ver1 조건은 버튼으로만 가져온다.
- 회원 확인 전 앱 스크립트를 실행하지 않는다. 로그아웃·계정 변경 때 요청과 개인 화면을 정리하고 기존 로컬 초안은 지우지 않는다.
- 백업은 본인 UID 및 revision을 확인한다. 다른 계정 기록을 자동 병합하거나 빈 기기로 기존 백업을 덮지 않는다.
- 원자료·개인 회사·재무자료·키는 공개 JSON에 넣지 않는다. 두 버전은 같은 검색 API와 호출 장부를 사용한다.

## 구현과 확인

소스 `index.html/css/js/data`만 배포 등록부에 포함한다. 연구는 [Python 서비스](../../services/homehunt/research/v2/README.md), 실험 결과는 [보고서](docs/model-report.md), 추가 신청은 [API 안내](docs/api-key-followup.md)를 따른다. 저장소 루트의 build/test/check 및 생성된 `/sungso/` 미리보기로 확인한다.

모델 결과는 엄격한 당시 공개자료 검증과 과거 재구성을 구분한다. 이번 실험은 과거 재구성이고 운영 확률은 보류 상태다. 자료 추가는 성능 개선을 보장하지 않는다.
