## 비교 이력과 해결 항목

- [P2, 해결] `enhancement-mobile-round1.png`에서 한글 손글씨가 신랑 머리에 겹쳤다. 오프닝 위치를 위로 옮기고 폭·한글 크기·윗 여백을 조정했다. 최종 전체·확대 비교에서 얼굴을 가리지 않는다.
- [P2, 해결] 처음의 다시 보기 문구가 모바일 터치 후 사진 위에 나타났다. 실제 Bootstrap 회전 화살표 아이콘을 사용하는 44×44 버튼으로 옮겨 사진 아래 오른쪽의 바위 위에 배치했다. 최종 캡처에서 얼굴·주요 문구와 겹치지 않는다.
- [P2, 해결] `enhancement-320.png`에서 영어 부제와 손글씨가 가까웠다. 320px 구간에서 부제 여백과 손글씨의 폭·위치를 따로 조정했다. 수정 후 `enhancement-320-final.png`를 열어 이름·부제·손글씨가 분리됨을 확인했다.
- [P1 기능, 해결] 카카오 약도 로더를 동적 script로 삽입하면 내부 document.write 때문에 지도가 준비되지 않았다. 공식 생성 코드를 파서가 읽는 별도 map.html 프레임으로 격리했다. 실제 지도 타일·장소 핀·출처와 확대 100m→50m·초기화 100m를 확인했다.
- [P2, 해결] 음악 설정의 가로 터치 영역을 38→44px로 넓혔다. 320px·390px의 표시되는 앱 버튼·링크·summary를 실제 DOM 크기로 검사했으며 44px 미만이 없다. 카카오 자체 지도 컨트롤은 외부 위젯의 원본이다.

수정 후 실제 캡처와 기준을 다시 한 비교 입력으로 열어 검토했다. 현재 보이는 P0/P1/P2 문제는 없다.

## 실제 브라우저 검증

측정 원본: `../../docs/invitation-v2-review/enhancement-browser-checks.json`.

|---|---:|---:|---:|

| 390×844 | 390 | 390 | 842.61 |
| 430×932 | 430 | 430 | 900.69 |
| 1440×1000 | 1425 | 480 | 975.28 |

데스크톱 scrollWidth는 세로 스크롤바 15px를 제외한 폭이다. 모바일과 PC 캡처를 열어 가로 넘침·잘림·겹침을 확인했다. 주요 상태의 캡처는 enhancement-letter, countdown, calendar, gallery, map-mobile, accounts-mobile, desktop 및 full-mobile 파일에 있다.

- 첫 진입은 음악 정지 상태다. 실제 버튼으로 음악 재생(aria-pressed=true)·음량 35→40→35%·일시정지(false)를 확인했다. 음량만 저장하고 재방문 자동 재생은 없다. 실제 OS 출력 장치에서의 음색·볼륨 청취 평가는 별도다.
- 손글씨 획 재생·다시 보기, 효과 끄기에서도 본문·날짜·사진 접근이 유지됨을 확인했다. OS 모션 감소는 CSS와 matchMedia에서 존중하며 실제 OS 설정 전환은 별도다.
- 카운트다운이 초 단위로 갱신됨을 확인했다. 멈춘 뒤 여러 작업 동안 같은 값이 유지되고, 재개하면 현재 시각으로 따라온다. 달력 탭·왼쪽 방향키·선택 상태·포커스 이동, 3월 6일 표시, 하트 감사 문구를 확인했다. 하트는 원격 전송이나 집계가 없다.
- 사진 확대 후 다음 03/05·왼쪽 방향키·Escape와 원래 사진 버튼으로 포커스 복귀를 확인했다. 실제 터치 스와이프는 실기기 검사로 남긴다.
- 공식 카카오 약도 핀·타일, 확대·초기화와 출처, 주소 복사의 성공 상태를 확인했다. 외부 두 지도 검색은 2.0 단계에서 실제 장소 결과를 확인했고 동일한 링크를 유지한다. 전화 연결은 번호를 검증했으며 실제 통화는 하지 않았다.
- 양가 계좌를 모두 펼쳐 ‘계좌 정보는 추후 안내’가 보임을 확인했다. 계좌 번호를 아직 받지 않았으므로 실제 계좌 복사 브라우저 검증은 해당 정보를 받은 후 진행한다. 입력 누락·부적합 번호 제외는 단위 검사로 확인했다.
- 링크 복사의 성공 안내를 확인했다. OS 클립보드 내용의 독립 읽기와 수신자 공유·캘린더 앱의 실제 등록은 수행하지 않았다. ICS 다운로드 자체는 2.0 단계에서 확인했고 이번 빌드에서도 같은 파일을 생성한다.
- 본문 이미지 다섯 장, 세 글꼴 loaded와 font check를 확인했다. 앱 콘솔 오류·경고 기록은 빈 배열이다. 실제 하드웨어와 카카오톡 인앱 검사는 남는다.
