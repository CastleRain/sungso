# Invitation VER2

- 선택한 포토형 디자인과 사용자가 제공한 실제 사진을 기준으로 하는 GitHub Pages용 하객 페이지다. 기존 회원 전용 `/invitation/`의 설정·찜·공동 선택과 독립한다.
- 예식은 2027-03-06 15:30 Asia/Seoul, 부산 목화웨딩홀 15층 벨리스홀이다. 내용의 원본은 `js/config.mjs`이며 `npm run build`가 정적 HTML·달력 파일을 생성한다.
- 사진은 사용자가 지정한 다섯 장만 웹용으로 축소한다. 원본·얼굴·색감을 수정하지 않으며 EXIF는 배포본에서 제거한다. 사용자는 2026-10-20 계좌 영역을 요청했고 양가 본인·부모님 슬롯을 준비하되 실제 계좌는 나중에 제공하기로 했다. 확정된 계좌만 표시하며 임의 번호·부모님 이름·개인 연락처는 만들지 않는다.
- 효과는 콘텐츠 접근을 막지 않는다. 모션 감소와 효과 끄기, 키보드 사진 탐색·닫기, JavaScript 실패 시 본문 읽기를 유지한다.
- `npm test`, `npm run build`, 실제 브라우저 390px/320px/430px/데스크톱 확인 후 기록한다. 원격 배포는 구현 검증과 구분한다.

## 진행 상황

### 2026-10-20 — 하늘빛 편지 개편

참고 글을 읽고 사진에서 가져온 하늘빛·아이보리·체리색과 손글씨 획 애니메이션, 자체 피아노 음악의 선택 재생·음량·정지, 카운트다운·달력 탭과 시간 멈춤·축하 효과, 카카오 공식 약도와 양가 계좌 빈 상태를 구현했다. 원본 손글씨 벡터는 기존 저장소 자산을 재사용한다. 모바일 자연 스크롤·모션 감소·사진 원본을 유지한다. 자동 검사 14개와 실제 음악·날짜·사진·약도·계좌 펼침, 320/390/430/1440px 확인을 기록한다.

**다음:** 사용자가 나중에 제공할 본인·부모님 계좌를 필요한 항목만 넣고 공개 배포 전 실기기 검증을 진행한다.

### 2026-10-19 — 포토형 VER2 제작

사용자가 선택한 첫 포토형 시안에 실제 사진 다섯 장과 목화웨딩홀 15층 벨리스홀·15시 30분을 반영했다. 첫 등장·사진 움직임·본문 나타남, 달력·갤러리·지도·공유를 구현했다. 자동 검사 11개·320/390/430/1440px·모달/이동/일정 다운로드·두 지도 검색을 확인했고 디자인 검증은 passed다. 실기기·OS 공유/클립보드 독립 검증과 공개 배포는 후속이다.

**다음:** 미리보기의 문구·효과를 검토한 뒤 최신 master의 배포 등록부에 별도 VER2로 통합한다.
