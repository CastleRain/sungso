# 성우와 소희의 청첩장 VER2

선택한 포토형 시안을 사용자의 실제 사진 다섯 장으로 구현한 정적 하객용 페이지다. 예식은 **2027년 3월 6일 토요일 오후 3시 30분, 부산 목화웨딩홀 15층 벨리스홀**이다.

하늘빛·아이보리·체리색을 실제 사진에서 가져온 편지형 포토 청첩장이다. 손글씨가 쓰이는 오프닝, 선택 재생 음악, 한국 날짜 D-day와 초 단위 카운트다운·달력 전환·시간 표시 정지, 일정 다운로드, 사진 확대·키보드 탐색·터치 이동, 카카오 약도·두 지도 앱·주소 복사·예식장 전화, 양가 계좌 펼침·복사, 기기 공유·링크 복사를 제공한다. JavaScript가 없어도 예식 정보·본문·사진·달력·외부 지도 링크·일정 파일을 읽을 수 있다. 효과와 음량만 이 브라우저의 localStorage에 저장한다. 축하 하트는 화면 안의 짧은 효과이며 원격으로 수집하지 않는다.

## 수정과 생성

`js/config.mjs`를 수정한 뒤 이 폴더에서 다음 명령을 실행한다.

```powershell
npm run build
npm test
npm run dev -- --port 8022
```

미리보기 주소는 `http://127.0.0.1:8022/sungso/invitation-v2/`다. 빌드는 의존성 설치 없이 실행한다. `src/index.template.html`·`src/map.template.html`과 공통 설정에서 `index.html`·`map.html`·`wedding.ics`를 생성한다. 종료 시각은 제공받지 않아 일정 파일에 임의로 넣지 않는다.

## 계좌와 음악

`js/config.mjs`의 `accountGroups`에서 신랑 측·신부 측 각각 본인·아버지·어머니를 선택해서 입력한다. 부모님 계좌는 선택이며 필요한 항목만 남겨도 된다. `relation`, `holder`, `bank`, `number`를 채우고 다시 빌드하면 입력된 계좌만 표시하고 복사 버튼을 연결한다. 실제 정보는 사용자가 나중에 제공하기로 하여 지금은 모두 비어 있다. 임의 번호를 테스트 화면에 노출하지 않는다. 배포 시 입력된 계좌가 공개 HTML에 포함되는 정적 페이지 구조다.

음악 ‘하늘빛 약속’은 이번 청첩장을 위한 자체 16마디 피아노 톤 연주로, 외부 녹음이나 샘플을 쓰지 않는다. 재생 버튼을 누를 때만 Web Audio를 시작하며 재생 여부를 저장해 자동 재생하지 않는다. 음량 조절·일시정지·반복 재생을 지원하고 탭을 떠나면 정지한다. 사용자가 보유한 곡을 쓰려면 웹용 파일을 `assets/audio/`에 두고 `music.src`와 제목을 수정한다. `music.mjs`가 이 경우 HTMLAudio 재생으로 전환한다.

## 사진

다섯 원본 `4B7A3899색.jpg`, `4B7A3198색.jpg`, `4B7A4247색.jpg`, `4B7A3370색.jpg`, `4B7A4052색.jpg`를 선택했다. 표지·세 장의 갤러리·마지막 사진으로 배치하며 확대 화면에서는 다섯 장을 모두 탐색한다.

원본은 프로젝트의 `사진/1_스냅사진/최종 셀렉/00_전체 모음_85장/`에 보존한다. `scripts/prepare-photos.py`는 Pillow로 방향을 적용하고 축소·압축·EXIF 제거만 수행한다. 인물·색감은 보정하지 않는다. 원본이 있는 작업 공간에서 `python scripts/prepare-photos.py`를 실행하면 웹 자산을 다시 생성한다. 실제 페이지는 최적화된 자산만 사용하며 사진의 절대 경로를 브라우저로 전달하지 않는다.

## 배포 범위

사용자 요청에 따라 공개 배포하는 별도 하객용 VER2다. 최신 `master`의 기존 회원 전용 `/invitation/` 선택 도구와 사용자 사진·예식장 Firestore 문서를 변경하지 않는다. 개인 연락처·하객 응답 수집은 추가하지 않는다.

GitHub Pages에 포함할 파일은 아래와 같다. 최신 저장소는 앱 등록부를 사용하므로 이 목록을 `config/apps.json`의 별도 `invitation-v2` 항목으로 등록한 뒤 사이트 전체 검사를 거친다. 이 오래된 작업 브랜치의 루트 전체를 운영 `master`에 덮어쓰지 않는다.

```json
{
  "id": "invitation-v2",
  "source": "apps/invitation-v2",
  "output": "invitation-v2",
  "files": ["index.html", "map.html", "wedding.ics", "css", "js", "assets"]
}
```

테스트·개발 서버·원본 사진·시안·검토 캡처·문서는 배포 목록에서 제외한다. 현재 공유 주소는 `https://castlerain.github.io/sungso/invitation-v2/`로 설정했으며 배포 결과는 진행 기록을 따른다. 로컬 검토에서 복사·기기 공유는 로컬 주소를 사용한다. 개인 도메인을 정하면 설정의 `canonicalUrl`을 바꿔 다시 생성한 뒤 공유·QR을 확정한다.

## 장소와 아이콘 근거

- 목화웨딩컨벤션의 주소·15층 위치는 [카카오맵 장소](https://place.map.kakao.com/24484800)의 실제 검색 결과와 대조했다. 홀 이름과 예식 일시는 사용자가 직접 확정했다. 대중교통은 연산역 인근으로 안내하며 주차 요금·무료 시간은 확정되지 않아 기재하지 않는다.
- 약도는 위 장소의 ‘약도 만들기’에서 생성한 카카오 공식 코드다. 페이지 근처에 스크롤했을 때만 독립 `map.html` 프레임을 읽는다. 로더는 `document.write`를 사용하므로 동적 script 삽입 대신 파서가 읽는 iframe으로 격리한다. 확대·축소·초기화·출처와 길찾기를 유지하고 로딩 실패 시 재시도와 외부 지도 링크를 제공한다. 별도 유료 키를 발급하지 않았다.
- [참고 글](https://brunch.co.kr/@design-staff/3)에서 상징 색·손글씨·필요한 순간의 인터랙션·자연스러운 모바일 스크롤을 참고했다. 사진과 디자인 전체를 복제하지 않는다.
- 손글씨 ‘Wedding’은 이 저장소의 기존 [wedding-lettering.mjs](https://github.com/CastleRain/sungso/blob/master/apps/invitation/js/wedding-lettering.mjs)의 원본 벡터를 재사용했다. 새로운 그림으로 근사하지 않고 실제 획을 순서대로 그린다.
- 아이콘은 [Bootstrap Icons v1.13.1](https://github.com/twbs/icons/tree/v1.13.1/icons) 원본이며 MIT 라이선스 전문을 `assets/icons/LICENSE.txt`에 보관한다.
- Noto Serif KR·Noto Sans KR·Nanum Pen Script는 Google Fonts에서 로드하고 대체 글꼴을 둔다.
