# 우리의 발자취

성우와 소희가 서로 만나러 간 이동과 함께한 장소·사진을 날짜별로 보관한다. `/sungso/journey/`에서 공통 Google 회원 로그인 뒤 사용한다.

1. **타임라인 추가**에서 누구의 기록인지 고르고 Google 타임라인 JSON을 선택한다. 미리보기 뒤 날짜별로 저장한다. 같은 원본·겹친 경로는 중복 저장하지 않으며 직접 수정한 기록을 유지한다.
2. **기록 추가 / 사진 추가**에서 날짜·사람·장소 제목·선택 메모를 작성한다. 위치가 있으면 지도에서 선택하거나 좌표로 입력한다. 모르는 시간·위치는 비워둘 수 있다.
3. **기록 목록 → 날짜 찾기**에서 저장한 달·날짜를 고른다. **이 순간 자세히**에서 사진과 기억을 읽고, 편집을 명시적으로 눌러 수정한다.
4. 지도에서 **재생**을 누르면 선택한 전체 기간의 이동을 시간순으로 보여준다. 큰 날짜·사람별 이동점·진한 최근 꼬리와 옅은 누적 경로가 함께 바뀐다. 한눈에 보기는 30초·1분·2분, 천천히는 3분·5분·10분이며 모드를 바꿔도 같은 시점이 유지된다.

기본 **한눈에 보기**는 대한민국과 제주가 보이는 넓은 시야 안에서 움직임을 보여준다. 국내 이동마다 지역을 확대하지 않고 주변 국가와 지명도 가린다. 현재 날짜에 도달한 위치가 한국 윤곽 주변을 벗어나면 세계지도가 드러나고 이동에 맞춰 시야가 넓어진다. 과거 해외 기록만으로 상대가 지금도 그곳에 있다고 가정하지 않는다. 도로·건물·작은 지명·분 단위 시각은 기본 보기에서 숨긴다. **천천히 보기**에서는 구간을 따라가며 알려진 시각과 상세 지도를 볼 수 있다.

기록 목록·달력·상세는 각각 접을 수 있다. MapLibre GL JS와 OpenFreeMap Positron으로 국내외를 같은 지도에서 표시한다. 지도를 직접 움직이면 자동 시야 변경을 멈추며 **이동 보기 / 따라가기**로 돌아온다. **전체 경로**는 선택 기간 전체 범위를 보여주고, 재생이 끝나면 지나온 경로 전체가 남는다. 한국 화면 범위는 카메라 구도이며 좌표의 국가를 판정하는 경계선이 아니다.

대표 장면을 뽑아 경로를 생략하지 않는다. 모든 실제 구간을 유지하되 화면용 좌표만 단순화하고, 정지·공백 시간을 압축한다. 전체 화면 시간의 30%를 기록 있는 날짜에 나누어 사진으로 복구한 날도 보이게 하고 나머지는 압축된 이동 시간에 비례한다. 시각이 겹치는 사람은 같은 실제 시계에서 움직인다. 경로가 없는 장소 사이와 GPS 공백은 선으로 잇지 않으며 상대의 지난 위치를 현재 위치로 밝게 표시하지 않는다. 날짜만 아는 사진에 정확한 시각을 만들지 않는다. 표시 날짜·알려진 시각은 기존 저장과 같이 한국 시간 기준이다.

브라우저는 썸네일과 긴 변 1600px 이하 JPEG를 만든다. 원본 사진과 원본 타임라인 파일은 자동 백업하지 않으므로 별도로 보관한다. 저장은 회원 전용 Render API·전용 Firestore 문서를 사용하며 공개 저장소에 개인 파일을 올리지 않는다. 한도에 도달하면 기존 내용을 유지하고 안내한다.

기존 `/footprints/`의 장소·방문·앨범 링크는 그대로 남아 있다. 네이버 길찾기 파일 가져오기와 MP4 제작 연결은 이번 범위에 포함하지 않는다. 지도 SDK가 연결되지 않아도 사진·메모·좌표 입력과 DB 다시 보기는 사용할 수 있다.

개발: 루트 `npm run build`, `npm run check`, `npm run build:services`. 합성 기록 검증은 `node apps/journey/tests/qa-server.mjs`의 `/sungso/journey/?qa=sample`, 해외·날짜변경선은 `?qa=motion`으로 확인한다. 실제 서비스에 검증용 쓰기를 하지 않는다. 지도 라이브러리의 버전·라이선스·원본 해시는 `assets/maplibre/`에 보관하며 지도 공급자 출처는 화면에 표시한다. 한국 집중 화면에는 Natural Earth의 공개 윤곽과 해안 주변 여유를 사용한다. 작은 섬 일부가 생략된 시각 자료이며 국가 판정이나 출입국 기록을 만들지 않는다. 출처·해시는 `assets/korea-focus-NOTICE.txt`에 보관한다.
