# Invitation VER3

- 사용자는 기존 올리브·종이 질감·시적인 문구와 굵은 한글 고딕 시안을 거절하고, 화이트·블루 및 https://toourguest.com/preview/porto 의 사진 위 영문 손글씨를 시각 기준으로 명시했다. 스타일을 임의로 빈티지/고딕 포스터로 되돌리지 않는다.
- 영문 Pinyon Script와 실제 SUIT를 사용한다. 원본 레퍼런스의 Dulcinea와 동일한 폰트라고 설명하지 않는다.
- 원본은 `js/config.mjs`; 사용자가 제공하지 않은 소개 답변·계좌·부모님 이름·교제일·주차/식사 정책을 만들지 않는다. 비어 있는 선택 영역은 공개 화면에서 숨긴다.
- 여섯 장의 사용자 사진만 사용하며 인물·사진 색을 생성/보정하지 않는다. 공개 페이지는 회원 앱과 독립하고 Firebase 개인 데이터에 접근하지 않는다.
- build/test 후 실제 브라우저로 320/390/430/1440px, 폰트·사진 이야기·달력·음악·지도·갤러리와 초기 화면을 확인한다. 검증되지 않은 OS 기능은 분리해서 기록한다.
