# Hub 작업 지침

[루트 지침](../../AGENTS.md)을 함께 따른다. `apps/hub/`는 배포 시 사이트 루트 `/sungso/`로 출력된다. `index.html`의 앱 링크와 PIN 후 직접 주소 복귀는 공개 출력 위치를 기준으로 유지한다.

- `js/app.js`: Firebase 비의존 파티클, 한국어 Flatpickr, 결혼식 D-day 초기 표시. Firebase SDK 10.12.0과 Flatpickr CDN 사용을 유지한다.
- `js/firebase.js`: `events` 실시간 구독과 추가·삭제·핀, D-day·목록·달력 렌더. 공통 Firebase 공개 설정만 가져온다.
- `events` 필드는 `date`(YYYY-MM-DD), `title`, `emoji`, `pinned`, `createdAt`이다. `pinned` 누락은 false다. 비어 있는 컬렉션의 기본 이벤트 8개 시딩을 임의로 반복하지 않는다.
- 핀이 없으면 결혼식 카드 1개, 있으면 핀된 이벤트만 남은 날짜순으로 가로 표시한다. 행 또는 핀 버튼은 같은 핀 토글을 실행한다.
- 주요 DOM 계약: `ddayRow`, 초기 `ddayNum`, `eventList`, `calGrid`, `calPopup`, `addForm`, `formTitle`, `formDate`.
- 홈 카드는 살림·집 준비와 우리의 여행으로 묶는다. 여행 결정 패널이나 오른쪽 패널용 여백을 추가하지 않는다.
- 기존 핑크·로즈 색상, 카드 둥근 모서리·hover·반응형을 유지한다. 홈 전용 스타일을 다른 앱의 공통 디자인으로 강제하지 않는다.

검증: PIN·앱 진입·홈 복귀·일정·핀·D-day·달력을 테스트 대역에서 확인하고 데스크톱·휴대폰의 링크와 화면 넘침을 확인한다. 실제 빈 DB를 사용한 검증은 시딩 쓰기를 유발하므로 사용하지 않는다.
