# 청첩장 공통 예식 일정과 Wedding 필기 검증

## 반영 범위

2026-09-15 사용자가 알려준 실제 예식 날짜·시간을 모든 청첩장 예시에 표시하도록 요청했다. `apps/invitation/js/wedding-date.mjs` 한 곳에서 일정과 한국어/영문/장식 표기를 만들고, 공통·투아워게스트 달력의 시작 요일·월 일수·강조일을 같은 일정에서 계산한다. 29종의 전체 본문·표지·목록 표지·팔레트·섹션 선택을 검사했다. 기존의 가상 예식 연도·월일·영문 월·장식 번호를 새 일정으로 맞췄다.

사진·이야기·장소·부속 식순은 여전히 예시다. 사용자 노트의 문자열, 기존 찜과 공동 선택 revision, 로컬 초안·내보내기 스키마, 회원 인증·Firestore 규칙은 바꾸지 않았다. 다른 앱의 운영 일정 문서를 수정하지 않는다.

제주(팔레트 배경), 서울·폴라로이드(종이 배경), 포르투(사진 위 흰 획)에 새 Wedding 필기를 넣었다. 직접 그린 SVG 획이 약 3.55초에 완성되고 4.3초에 배경과 함께 사라진다. 기존 `reference-flow`의 실제 글자 가시성 트리거·재생 기억을 사용한다. 같은 탭에서 스크롤 복귀·색상 변경·예시 재진입에는 재생하지 않으며 새로고침에는 다시 볼 수 있다. 새 필기는 원본 샘플에서 복사한 자산이 아니다.

아직 쓰지 않은 획의 둥근 끝점은 숨기고, 포르투의 기존 제목은 필기 후 나타나도록 겹침을 정리했다. 썸네일과 기존 두 살롱 오프닝에는 추가 오버레이가 없다. 연출 끄기·모션 감소는 본문을 바로 보여준다.
