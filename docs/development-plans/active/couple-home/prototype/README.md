# 홈 프로토타입

[index.html](index.html)을 브라우저에서 연다. 별도 Codex 플러그인은 필요하지 않다. 폰트·아이콘 표시에는 인터넷이 필요할 수 있다. 창을 좁히면 모바일 배치를 볼 수 있다.

- [데스크톱](desktop.png), [모바일](mobile.png), [홈 편집](edit.png)
- [원본 HTML fragment](source.html): 수정·재생성 참고용이며 독립 실행 문서가 아니다.

밝은 분홍 기본 시안이다. 기존 대화의 Tweak 기기·팔레트·로그인 화면 비교 패널은 독립 HTML에 포함되지 않는다. 실제 홈 편집, 날짜 화면 이동, 메모 입력은 시안 내부에서만 동작하며 새로고침하면 초기화된다. 실제 로그인·Firebase·파일 접근·공유 저장·앱 이동은 구현되지 않았다. 예시 날짜와 메모는 운영 데이터로 시딩하지 않는다. 실제 개발에는 PLAN.md의 메모 더보기·삭제, 권한과 동시 편집 등 시안에 없는 요구도 포함된다.
