# 이전 NAVER 키 폐기 후속

새 Client Secret의 발급과 기존 Render 서비스 적용은 확인했다. 이전 키의 폐기는 아직 확인하지 않았다. 실제 키·회원 식별자·관리자 연락처는 이 문서에 넣지 않는다.

[NAVER 공식 공지](https://developers.naver.com/notice/article/33626)에 따르면 2026-08-26부터 재발급 후 이전 키와 새 키가 30일간 함께 유효하다. 이전 키를 즉시 삭제하려면 개발자센터에 문의해야 한다. 재발급만으로 노출된 키가 무효화됐다고 기록하지 않는다.

## 문의 초안 — 미발송

제목: 재발급 이전 Client Secret 즉시 삭제 요청

> 안녕하세요. 제가 소유한 ‘성우소희’ 애플리케이션의 이전 Client Secret이 공개 파일에 포함되어 있던 것을 확인했습니다. 2026-09-14 한국 시간에 새 키를 발급하고 운영 서버의 장소 검색·블로그 검색 설정을 교체했습니다.
>
> 현재 새 키와 애플리케이션 설정은 유지하면서, 재발급 직전의 노출된 키만 즉시 삭제·무효화해 주세요. 30일 중복 유효 기간을 기다리지 않고 이전 키의 사용을 차단하려는 요청입니다. 처리 완료 시각과 이전 키의 무효화 여부를 회신 부탁드립니다.
>
> 비밀값은 문의 본문이나 첨부에 포함하지 않았습니다. 대상 애플리케이션 식별에 필요한 정보는 공식 비공개 접수 경로에서 제공하겠습니다.

초안은 아직 발송하지 않았다. 공식 비공개 접수 경로와 발송 승인을 확인한 뒤에만 전송한다. 공개 게시판에 비밀값이나 관리자 정보를 게시하지 않는다.

## 완료 근거

- 즉시 삭제를 요청한 경우: 공식 접수·처리 완료 회신과 대상 이전 키의 무효화 근거를 비공개로 보관하고 비민감 결과만 RESULTS에 기록한다.
- 30일 유효 기간 종료를 기다리는 경우: 재발급 날짜만으로 완료 체크하지 않는다. 공급자의 만료 확인 근거를 확보한다. 현재 정확한 재발급 시각과 공급자 만료 시각은 확인하지 않았다.
- 앱 삭제·재생성이나 반복 재발급으로 폐기를 추정하지 않는다. 기존 Maps·Kakao·공공자료 설정과 사용량 한도를 유지한다.
- 과거 Git 이력과 외부 사본 정리는 별도 후속이다. 키 폐기가 과거 자료 노출의 삭제를 뜻하지 않는다.
