# VER6.1 F / G — 이야기 밖의 새로운 경험

2026-10-28. 사용자가 기존 A–E는 이야기의 차이가 주로 보인다고 알려, 예식일·사진첩·도착 안내·계좌·방명록·빠른 메뉴를 바꾸는 두 시안을 별도로 만들었다.

## 구현

- **F / Flow:** 기존 손글씨 표지가 스크롤에 따라 프레임으로 정리되고, 날짜 카드가 짧게 머무르며 달력과 남은 시간이 한 장으로 완성된다. 겹친 인화사진이 대표 사진에 모이고 도착 안내 카드·약도가 펼쳐진다.
- **G / Air:** 아치형 날짜 카드와 가벼운 펼침, 네 장의 사진이 대표 사진으로 모이는 구성. 긴 고정 장면 없이 이어서 읽는다.
- 공통 계좌는 신랑/신부 측을 고른 뒤 본인·아버지·어머니를 선택하는 단일 카드다. 번호 복사와 완료 표시를 제공한다. 예시 정보만 사용한다.
- 방명록은 봉투 모양 진입부→줄이 있는 편지 작성면→저장한 메시지 카드로 이어진다. 체험 자료는 해당 시안·기기에만 저장된다.
- 예식·사진·길찾기·더 보기로 구성한 하단 메뉴는 읽는 위치에 반응한다. 큰 글씨, 예식 정보 PNG, 일정 저장, 주소/공유, 기존 이야기 세 장과 전체 음악을 유지한다.
- 기존 루트, `/v6/`, A–E의 177개 파일은 바이트 단위로 보존한다. 새 파일 28개는 `/lab/experience/` 아래에만 추가한다.

## 조사

[새 연구](../invitation-lab/round2-research.md)에 Apple 공식 모션 지침·제품 구조, WebKit 모션 접근성, Theirmood/To Our Guest 기능을 기록했다. 직접 본 화면과 문서로만 확인한 사실을 구분한다. 참고 제품의 리소스·문구를 가져오지 않고 기존 커플 사진·글꼴로 구현했다.

## 확인 결과

- 전체 `npm run check` 2,089개 통과. 마지막 모션 진행 구간 변경 뒤 신규 동작 17개 재검사 통과. `git diff --check` 통과.
- F 실제 320/390/430/768/1440px 가로 넘침 없음. 320px 큰 글씨 모달도 가로 넘침 없음. G 사진첩 390/1440, 비교실 320/390/1440 확인.
- F 날짜 진행 0.7533과 3D 변형 중간값, 짧은 sticky 상태 확인. F/G 사진첩의 중간 배율·스크롤 변화는 [사진첩 QA](../invitation-lab/round2-gallery-qa.md)에 기록했다.
- 7장 선택·확대·다음/이전·전체 보기·닫은 뒤 선택 복원, 교통 탭, 양가/받는 분 선택, 일정 선택창, 빠른 메뉴를 확인했다.
- 체험 메시지 작성·저장·재로딩 유지·삭제 확인. 운영 DB 쓰기 없음. 복사 완료 UI는 확인했으나 이 실행의 IAB 가상 클립보드는 비어 있어 실제 OS 붙여넣기는 확인하지 못했다.
- 오디오 한 개, 재생 시간 증가, 대화상자 왕복 재생 유지. 효과 끄기 시 숨은 본문 0·날짜/사진 변형 없음. 관측된 브라우저 오류·경고 없음.
- 약도의 일시적인 `Not found`는 검증 중 전용 출력 폴더가 재생성되는 시점에 발생했다. 최종 빌드 후 재로딩해 실제 카카오 약도와 장소 표시를 확인했다.
- 초기 정적 리소스 F 1,290,415B / G 1,290,397B, JS gzip 약 33.3KB. 이 수치는 실제 LCP/CLS/FPS가 아니며 전체 MP3와 지연 사진을 제외한다.

## 남은 실기기 확인

실제 iOS/Android 터치 감도, 브라우저의 자동재생 허용, OS 클립보드·지도 앱·캘린더·카카오톡 카드와 PNG 저장. 이 비교안은 운영용 계좌/방명록·사진 관리에 연결하지 않는다. 선택된 시안을 운영 적용할 때 기존 서버·두 사람 관리 권한을 연결하고 별도로 검증한다.

**다음:** F와 G 중 날짜·사진첩·도착 안내의 선호 동작을 골라 한 개의 운영 버전으로 조합한다. 이전 이야기 시안은 선택 자료로 계속 보관한다.
