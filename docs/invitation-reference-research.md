# 공식 샘플 여섯 가지와 재현 범위

2026-09-14에 사용자가 알려준 두 업체의 공개 샘플에서 서로 다른 표지 세 개씩을 골랐다. 이번 기준은 새로운 장면을 덧붙이는 것보다 **원본의 사진 비율, 서체 배치, 긴 본문 순서와 여백을 가깝게 옮기는 것**이다. 원본 사진·실명·예식 정보는 저장소의 가상 예시로 바꾼다.

## 긴 본문의 흐름

살롱의 현재 샘플은 **표지 → 인사 → 짧은 글 → 두 사람 소개 → 날짜 → 오시는 길 → 갤러리 → 인터뷰 → 이야기 → 안내 → 마음 전하기 → 참석 의사 → 방명록 → 마무리**로 이어진다. 다른 두 살롱 샘플도 흰 바탕의 인사, 두 인물 소개, 달력, 사진, 교차 타임라인, 계좌 펼침과 참석 의사를 갖춘 긴 문서다. 표지만 바꾸고 기존의 짧은 본문을 붙이는 방식으로 축약하지 않는다. [살롱 현재 샘플](https://salondeletter.com/w/iojsro5wcc), [폴라로이드](https://salondeletter.com/w/fpglo0twky), [네 모서리](https://salondeletter.com/w/fb7i16olnt)

투아워게스트는 **표지 → 인사 → 전폭 사진 → 큰 날짜 → 달력 → 가족 → 인물 소개 → 교차 타임라인 → 갤러리 → 장소 → 마음 전하기 → 방명록 → 안내 → 참석 의사 → 마무리**의 흐름을 재구성한다. 세 표지가 서로 다른 반면 본문 구성에는 공통점이 많다. 실제 원본의 광고·상거래 영역을 제외한 순서를 따른다. ## 같은 연출을 다시 보지 않도록

서울 원본에서 인사 문구가 처음 화면에 들어올 때 아래에서 나타났고, 위로 돌아간 뒤에도 이미 나타난 상태를 유지하는 것을 확인했다. 이 동작을 새 예시의 본문 기준으로 삼는다. 새 여섯 예시는 자연스럽게 이어지는 세로 문서이며, 읽은 문구와 사진을 매번 다시 숨겨 재생하지 않는다. 살롱의 짧은 표지 오프닝도 같은 미리보기에서 반복하지 않는 방향으로 연결한다. [서울 원본](https://my.toourguest.com/preview/seoul), [살롱 오프닝 원본](https://salondeletter.com/w/fb7i16olnt)

원본의 밀리초 단위 길이와 이징은 측정하지 않았다. 따라서 구현의 재생 시간이 원본과 같다고 단정하지 않는다. 투아워게스트 표지에서 관찰한 반복 꽃잎은 이번 요청에 맞춰 생략한다. 모션 감소 설정과 일반 보기에서는 내용을 바로 읽을 수 있어야 한다.

## 의도적으로 다른 부분

- **사진과 글:** 기존의 가상 커플 사진·예시 인사말·2030년 5월 18일·예시 웨딩홀을 사용한다. 원본 인물의 사진, 실제 연락처·계좌, 개인 일화와 인용문은 가져오지 않는다. 사진이 세 장이므로 원본의 많은 사진 수와 동일하지 않으며 자르기와 배치로 구분한다.
- **서체:** 원본의 별도 폰트 파일은 복제하지 않는다. 필기체와 명조는 공개 서체인 Pinyon Script·Noto Serif KR 등으로 대체한다. 사진 비율과 서체 크기·정렬을 맞추어도 획 모양까지 완전히 같지는 않다.
- **기능:** 자동으로 열리는 참석 팝업, 광고, 화환 주문, 결제, 실제 계좌·통화·외부 지도 연결은 포함하지 않는다. 펼쳐보는 정보와 참석 의사는 비교용 예시이며 응답을 받지 않는다.
- **기존 선택 기능:** 팔레트, 사진 배치, 이야기·갤러리·교통·마음 전하기·참석 여부·방명록 표시 옵션은 유지한다. 옵션을 바꾸면 원본의 기본 구성과 달라질 수 있다. 갤러리 사진 확대와 옆으로 넘기기를 지원한다.

이 문서는 원본 조사와 재현의 기준을 기록한다. 실제 휴대폰의 성능, 모든 원본 팝업과 부가 서비스는 확인하지 않았다. sungso의 테스트·브라우저 확인·배포 완료 여부는 별도의 검증 기록으로 판단한다.
