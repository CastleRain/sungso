# 청첩장 약도와 지도 연결 검증

2026-09-15. 사용자가 지정한 예식장의 지도 두 곳과 공식 약도를 회원 공통 설정에 반영하기 위한 기능이다. 실제 장소명·주소·약도 파일·회원 식별자는 공개 소스에 포함하지 않는다.

## 변경

- `venue.naverUrl`, `venue.kakaoUrl`을 추가하고 기존 `mapUrl`을 유지한다. 지도 서비스별 버튼을 표시하며 기존 링크가 같은 서비스면 중복을 제거한다. HTTPS 링크만 허용하고 텍스트/속성을 이스케이프한다. 자동 검색 API·위치 조회·별도 키는 없다.
- 프로필의 `mapImageId`로 약도 1장을 별도 참조한다. 갤러리 최대 20장·대표 1장은 그대로이며 고유 이미지 최대 수는 22장이다. 기존 회원 사진 문서·압축·완전한 사진 로딩·revision·원자 저장/삭제를 재사용한다. 약도는 갤러리나 표지에 자동 포함하지 않는다.
- 모든 29종의 오시는 길에서 약도 전체 비율과 주소·층·지도 버튼·교통·주차를 표시한다. 약도 확대 모달은 전체 이미지를 표시하며 닫기·Escape·권한 변경 시 개인 이미지/캡션을 정리한다. 약도가 없으면 가상 약도를 만들어 채우지 않는다.
- 새 필드가 없는 이전 프로필을 빈 값으로 읽는다. 기존 찜·공동 디자인 선택·초안 키·회원 인증·다른 앱 규칙·Spark 요금제는 유지한다.

## 자료 확인

사용자가 제공한 네이버/카카오 장소 링크가 같은 이름·도로명 주소를 표시하는지 브라우저에서 확인했다. 업체 공식 오시는 길의 주소·지하철·예식 시 셔틀·버스·주차 안내와 공식 약도 PNG를 별도로 확인했다. 층은 사용자가 지정한 정보다. 약도는 372×372px이며 서버의 Last-Modified가 2019년이다. 실시간 지도나 현재 도로의 정밀 측량을 뜻하지 않는다. 약도 파일은 Git에 넣지 않고 회원 공통 설정에만 저장한다.

공식 홈페이지의 교통·주차 안내는 확인 시점의 공개 정보이며 향후 예식일에 같은 운행 간격/지원 조건이 유지된다는 확약은 아니다. 셔틀 세부 간격은 생략하고 주차 지원은 현장 안내 확인 문구를 함께 사용한다. 웹 지도 버튼은 최신 장소 정보를 열 수 있게 한다.
