# 스크롤 청첩장 일곱 가지 — 2026-09-14

## 적용 범위

기존 매거진에 필름·온실·추억장·별자리·봉투·산책길을 더했다. 20개 디자인 ID·회원 인증·찜·공동 선택 revision·로컬 초안·Firestore 규칙은 유지한다. 실제 하객용 공개 기능은 추가하지 않는다.

| 디자인 | 스크롤 연출 | 함께 쓰는 기존 체험 |
|---|---|---|
| 매거진 | 사진 확대와 지면 전환 | 인터뷰·화보 |
| 필름 | 가로 셔터와 흑백에서 컬러로 현상 | 수동 현상 단계 |
| 온실 | 타원형으로 열리는 장면과 잎·꽃 | 계절·꽃 피우기 |
| 추억장 | 종이 경첩을 축으로 넘기는 장면 | 기억 페이지·스티커 |
| 별자리 | 별빛의 깊이와 확대 이동 | 별 잇기·세 가지 이야기 |
| 봉투 | 편지가 들리며 펼쳐지는 장면 | 봉투 열기·접힌 편지 |
| 산책길 | 가로로 이어지는 장면과 길 그리기 | 산책 지점 선택 |

목록에 일곱 바로가기와 해당 카드의 스크롤 진입 링크를 추가했다. 문서의 세로 스크롤을 사용하며 별도 스크롤 영역·휠/터치 가로채기·스크롤 상태 저장은 없다. 긴 본문은 마지막 줄까지 이동한 뒤 다음 장면으로 전환한다. 연출 끄기와 기기의 모션 감소에서는 일반 본문을 읽는다.

중첩된 체험 컨테이너를 DOM에 유지하고 장면 노드만 배치한다. 화면 크기·편지 펼침·꾸미기 변경 후 장면 위치를 복원한다. 회전 중 키보드 포커스가 들어오면 장면을 먼저 펼친 뒤 버튼 위치를 측정한다.
