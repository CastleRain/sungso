# 모바일 청첩장 예시 확장 참고 조사

2026-09-14에 사용자가 제공한 네이버 블로그와 브랜드 공식 사이트·공개 샘플을 조사했다. 비교 앱에 추가할 예시의 구성과 동작을 찾기 위한 조사이며, 외부 서비스의 사진·문구·음원·로고·코드를 가져오지 않았다. 신규 예시는 기존 가상 커플 자료와 자체 구현을 사용한다.

## 사용자 제공 링크

- [살롱드레터 네이버 원문](https://blog.naver.com/salondeletter/223882221463)은 검색 도구에서는 오류였으나 브라우저에서 정상으로 열렸다. 본문의 샘플 이미지 링크에 연결된 [공식 샘플](https://salondeletter.com/w/sample1_2)까지 확인했다.
- [투아워게스트 스마트스토어 상품](https://smartstore.naver.com/toourguest/products/10289249311)은 검색 도구에서 본문을 읽지 못했다. 대신 [공식 샘플 목록](https://my.toourguest.com/home/mobile)에서 [서울 샘플](https://my.toourguest.com/preview/seoul)을 직접 열어 화면과 본문을 확인했다.

## 추가로 확인한 공식 소개

- [핀오늘](https://finoneul.com/)은 사진의 깊이·빛·타이틀 연출과 스크롤 반응을 공식 소개한다. 개별 시안의 실제 동작까지 검증하지는 않았다.
- [So New Wedding](https://invitation.sonewwedding.com/)은 아치·필름·매거진·미니홈피와 조명·전광판·스크래치·영수증·TV 형태를 소개한다. 검색 결과와 실제 페이지의 템플릿 개수가 달라 정확한 개수는 근거로 사용하지 않는다.
- [유어스레터 샘플 목록](https://yoursletter.com/mobile/explore)은 무드 태그와 한 줄 설명으로 디자인을 탐색하게 한다. sungso 목록도 모음 이름만 나누는 대신 검색·분위기·직접 해볼 동작을 함께 보여주는 방향으로 개선한다.

## 구현·검증 경계

- 목표는 첫 사진의 짧은 애니메이션만 바꾸는 것이 아니라 표지·본문·사진·식순·안내·마무리까지 각 예시의 성격을 유지하는 것이다.
- 비교·꾸미기와 공동 선택은 기존 앱 계약을 따른다. 외부 샘플의 RSVP, 방명록, 사진 업로드, 지도·전화·송금은 실제 운영 기능으로 연결하지 않는다.
- 체험 상태는 메모리에만 유지하며 필수 정보를 읽기 위해 체험을 완료하도록 강제하지 않는다. 버튼·키보드·모션 감소·전체 문서 스크롤을 지원한다.
- 이 문서는 외부 샘플 관찰 기록이다. sungso 구현의 실제 성공 여부, 자동 검사·브라우저 검증·배포 결과는 [별도 검증 기록](invitation-verification.md)에 남긴다.
