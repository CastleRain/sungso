# 모바일 청첩장 선택 앱 — 로컬 검증

검증일: 2026-09-13. 범위는 홈 통합, 여섯 예시, 옵션 미리보기, 찜·공동 선택, 선택서 출력이다. 공개 배포와 하객용 실제 제작은 포함하지 않는다.

## 자동 검사

| 검사 | 결과 |
|---|---|
| `npm run build` | 6개 앱, 공개 파일 209개 생성 |
| `npm test` | 공유 작업 트리의 1,436개 통과 |
| `npm run check` | 1,436개 통과, 정적 참조 324개·JS 문법 124개 통과 |

| Firestore Emulator | 전용 4개 통과 |
| `git diff --check` | 통과 |

Node 23.3.0, Firestore Emulator 1.22.0, Java 23으로 실행했다. 루트 검사 중 로컬 HTTP 포트 개방이 필요한 검사는 샌드박스 밖에서 다시 실행해 통과했다. 서비스 구현·규칙 변경이 없어 서비스 번들 재빌드는 이번 범위에 포함하지 않았다.

신규 단위 검사는 여섯 디자인 기본값, 옵션 정리·내보내기, 사람별 찜 병합, 번호 충돌, 임시 설정과 공동 데이터 분리, 손상되거나 사용할 수 없는 localStorage, hash 직접 접근, 필터, 섹션 구성, 메모 이스케이프, 저장 실패·중복 저장 차단, 홈 순서, PIN 실행 순서를 다룬다.

Emulator는 `demo-homehunt`와 localhost만 사용했다. 운영 코드의 `firestore-adapter.mjs`에 테스트 SDK를 주입하고 현재 `firestore.rules`를 적용했다. 비로그인 클라이언트의 조회가 문서를 생성하지 않음, 두 사람의 동시 찜이 모두 남음, 기존 리조트 `couplePicks/main`과 최종 디자인 보존, 같은 번호의 공동 선택 두 건 중 한 건만 성공함, 최신 번호 확인 후 재저장, 오프라인 쓰기 거부를 확인했다.

## 보존과 한계

기존 공개 앱 주소·허브 일정 코드·PIN 정책·저장 키·Firestore 규칙은 변경하지 않았다. 신규 앱은 공통 Firebase 공개 설정만 가져오며 다른 앱 초기화나 여행 결정 패널을 로드하지 않는다. 이미지 네 장은 생성 후 앱의 공개 자산으로 저장했고 원본 프롬프트는 배포 대상에서 제외했다.

이번 브라우저 검사는 Codex 내장 브라우저의 두 화면 크기와 로컬 대역 기준이다. 실제 iOS Safari·Android Chrome 기기, 운영 DB를 통한 기기 간 공동 저장, 원격 Pages 배포는 별도 확인 대상이다. Firebase 트랜잭션 자체는 실제 Emulator에서 검증했다. 이번 작업은 기존 Travel·WeCost의 동시에 진행 중인 변경을 되돌리지 않았다.

**다음:** 공개 배포를 별도로 확인하고, 두 사람이 저장한 선택서를 실제 제작·하객용 공개 페이지 작업에 전달한다.

브라우저는 별도 8021 포트의 메모리 대역에서 검증했다. 오른쪽 무대 커튼의 초기 변형 기준점을 수정하고 닫힌 상태에서 양쪽 커튼이 사진을 가리는 것과 열린 상태를 다시 확인했다. 카메라의 빠른 재클릭도 현상 애니메이션을 다시 시작하도록 처리했다. 체험 결과는 설정 재렌더링에 유지되고 타이머·리스너는 화면 전환 시 정리한다. CSS의 모션 감소와 즉시 상태 전환은 코드·단위 검사로 확인했으며 OS 설정을 바꾼 실제 기기 검사는 진행하지 않았다.

새 디자인의 JSON 계약은 단위 검사와 Emulator로 검증했다. 브라우저의 실제 JSON 파일 다운로드 검사는 위 최초 여섯 디자인 구현 때의 결과이며, 이번 추가 검증에서는 공동 저장된 별자리의 클립보드 출력까지 확인했다. 검사 중 운영 DB에 접근하거나 테스트 기록을 쓰지 않았다. 기존 8017 미리보기 서버는 선택 스냅샷을 보관해 재시작했고, 찜·선택·변경 번호·쓰기 횟수가 전후 동일함을 비교했다.

**다음:** 두 사람이 특별한 6종의 동작과 색감을 비교하고 실제 제작 페이지의 디자인을 결정한다. 실제 모바일 기기·공개 배포 검증은 별도다.

사용자 확정 후 최신 `origin/master`에서 별도 작업 브랜치를 만들고 청첩장과 홈 연결 변경만 `4014d001349e840a84dd6e82cba845dc641d7b09`로 커밋해 master에 반영했다. 기존 여행·WeCost 변경은 최신 master의 내용을 보존했다. 통합 소스의 `npm run check` 1,447개도 통과했다.
