# 투아워게스트 공식 샘플 재현 기준

2026-09-14 확인. 사용자가 준 [스마트스토어 상품](https://smartstore.naver.com/toourguest/products/10289249311)의 공급자 [공식 모바일 목록](https://my.toourguest.com/home/mobile)에서 서울·포르투·제주를 골랐다. 세 표지는 사진 띠·전면 사진·단색 이름 카드로 구분된다. 목록의 각 샘플 버튼을 눌러 실제 공개 예시를 확인했다. 원본의 사진·실명·연락처·계좌·인용 문구는 복제하지 않고 저장소의 가상 예시로 바꾼다.

## 1. 서울 — 흑백 사진 띠

출처: [서울 실제 샘플](https://my.toourguest.com/preview/seoul).

- 1280×720 화면에서 흰 초대장 너비 400px, 상단 여백 48px, 사진 320×320px 두 장, 사진 사이 20px. 모서리는 약 12px이며 여백에 작은 세로 영문·날짜·필름 번호가 있다. 첫 사진은 y=88px, 다음 사진은 y=428px였다.
- 본문은 흰 바탕과 얇은 십자 장식, 중앙 정렬 인사말, 너비 가득한 세로 사진으로 이어진다. 달력·인물·교차 타임라인 뒤에는 3열 사진 갤러리가 나온다.
- 문구는 첫 진입 전 opacity 0·translateY(40px), 진입 뒤 1·0이다. 아래로 읽었다가 맨 위로 돌아가도 이미 읽은 문구는 1·0을 유지했다. 화면을 넘길 때마다 같은 장면을 재생하는 방식이 아니다.
- 표지 꽃잎은 시간에 따라 계속 움직였다. 이번 구현에서는 사용자 요청에 맞춰 이 반복 장식을 생략한다.

## 2. 포르투 — 사진 위의 큰 하트

출처: [포르투 실제 샘플](https://my.toourguest.com/preview/porto).

- 390×844 첫 화면은 390×844 사진으로 꽉 찬다. 중앙에는 흰 필기체 제목 36px과 작은 이름·일시 한 줄이 있다. 원본 서체는 Dulcinea다.
- 거친 손그림 느낌의 흰 이중 하트가 사진보다 크게 확대되어 위·양옆·아래로 잘린다. 완료 상태의 장식 SVG는 화면의 두 배 크기이며 scale(2)였다. 하트의 일부만 보이는 넉넉한 프레이밍이 핵심이다.
- 최초에는 흰 막이 덮인 상태였다가 사진·제목·하트가 보였다. 정확한 지속 시간과 이징은 측정하지 않았다. 이후 본문은 일반 세로 문서이며 중앙 인사말과 전폭 사진으로 연결된다.
- 갤러리는 paging 사진 목록이다. 표지 외 본문 구성은 서울과 상당 부분 공통이다. 임의의 입체 회전이나 새 장면을 삽입하지 않는다.
- 재현 시 필기체는 저장소에서 사용 가능한 서체로 대체하고, 반복 꽃잎은 생략한다.

## 3. 제주 — 이름과 여백

출처: [제주 실제 샘플](https://my.toourguest.com/preview/jeju).

- 390×844에서 표지는 높이 872px, 배경 rgb(180,123,123), 흰 명조 48px 이름 / & / 이름 세 줄이다. 각 줄 높이는 48px, 시작 y는 168·296·424px다. 원본은 Maruburi이며 위아래 빈 공간이 크다.
- 일시와 장소는 18px로 하단에 두 줄 배치한다. 사진 없는 표지 이후에는 흰 인사말·전폭 세로 사진, 같은 장밋빛 바탕의 큰 월일·연도 카드가 이어진다.
- 달력은 연한 바탕, 얇은 구분선, 일요일 강조와 예식일 원형 표시다. 하단에 남은 일·시·분·초 네 작은 카드가 있다.
- 인물 소개는 옅은 분홍 배경 위 흰 사진 카드 두 개다. 타임라인은 중앙 선과 점을 사이에 두고 사진/문구가 네 번 교차한다. 390px에서 사진은 약 147px 정사각형이다. 갤러리는 한 장씩 보는 형태와 현재 번호가 있다.
- 본문 진입 때 문구·사진이 부드럽게 나타났다. 표지에 종이 접기·문 열기·카메라 이동은 없었다.

## 공통 구현 결정

아래는 원본의 새 사실이 아니라 sungso의 구현 기준이다.

- 긴 세로 구성을 유지한다. 새 여섯 예시는 기존 고정 장면 엔진에 억지로 끼우지 않고 한 번만 나타나는 본문 연출을 적용한다. 스크롤 역방향에서 이미 읽은 요소를 다시 숨기지 않는다.
- 표지 → 인사 → 큰 사진 → 날짜 타이포 → 달력 → 가족 → 인물 → 교차 타임라인 → 갤러리 → 장소 → 마음 전하기 → 방명록 → 안내 → 참석 의사 → 마무리의 긴 흐름을 재구성한다. 실제 결제·화환 구매·외부 지도 요청·연락 기능은 예시로 대체한다.
- 새 CSS 목표값은 40px 이동·800ms 등장·짧은 순차 지연이다. 원본의 정확한 시간 측정값으로 표현하지 않는다. 모션 감소와 일반 보기는 즉시 완전히 보인다.
- 표지 사진 재등장·동일 접힘 물체 재등장을 피한다. 내부 데이터는 기존 예시 자산을 쓰되 배치와 자르기를 구분한다.
- 이 문서는 CUA에서 관찰한 1280×720 및 390×844 화면과 읽기 전용 DOM 치수에 근거한다. 실제 휴대폰 성능·추가 브라우저·모든 모달은 미검증이다. 원본 JS/CSS 묶음을 가져오거나 실행 코드를 복사하지 않았다.
