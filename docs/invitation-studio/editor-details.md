# 스튜디오 세부 조절·문구·사진·다음 단계

2026-10-29

## 사용 흐름

- 전체 분위기에서 서체를 고른 뒤 글자 크기 90–120%, 줄 간격 90–140%, 장면 여백 70–140%를 5% 단위 슬라이더로 조절한다. 기존 세 가지 기본 표현도 유지한다.
- 장면 옵션의 ‘이 장면만 세부 조절’을 펼쳐 개별 값을 지정할 수 있다. 켜는 순간 현재 전체 값을 가져오며, 해제하면 다시 전체 값을 따른다. 표지는 사진 높이를 유지하기 위해 글자 크기·줄 간격만 제공한다. 기존 벡터 손글씨·음악 조작·입력 폼은 본래 크기를 유지한다.
- 하단 ‘다음’은 전체 분위기 → 표지·손글씨 → 실제 읽는 순서의 장면 → 마지막 장면·메뉴 → 문구·사진으로 이동한다. 격자 사진첩의 세부 열/비율 및 켜진 추가 장면만 포함한다. 마지막은 이름·메모를 입력하는 보관함으로 연결하며 자동으로 저장하지 않는다.
- ‘문구·사진’에서 두 사람·부모님 표시 이름, 초대글, 이야기 세 장, 마지막 인사를 입력한다. 입력을 비우거나 해당 항목을 초기화하면 원래 문구로 돌아간다. 사진은 설명 없이 추가·순서 변경·빼기·되돌리기를 제공한다.

## 저장과 실제 반영 범위

디자인·전체/장면별 수치는 기존 버전 1 조합 URL, 최대 40개 보관함, 디자인 JSON 파일에 포함된다. 기존 링크와 파일은 새 수치를 100%로 해석한다.

문구와 시안 사진은 이 브라우저의 IndexedDB에 자동 저장되는 별도 현재 초안이다. ‘내용 파일’에는 문구·추가 사진·현재 디자인을 함께 내보내며 다른 기기에서 불러올 수 있다. URL과 기존 디자인 보관함에는 문구·사진을 넣지 않는다. 기존 최신 청첩장에 문구 전용 DB/API가 없으므로 이 작업에서 새 운영 저장 서버를 만들거나 하객 화면의 글을 변경하지 않았다.

실제 하객 사진은 ‘실제 사진 관리 열기’로 기존 `/manage.html`을 같은 탭 안에서 연다. 기존 두 사람 Google 승인과 서버 검증이 그대로 적용된다. 이 관리 화면에서 명시적으로 ‘청첩장에 반영’을 누르는 경우 기존 하객 사진첩도 바뀐다. 부모 스튜디오는 토큰을 받거나 관리 API를 호출하지 않는다. 로그인 팝업이 불편한 환경에는 새 탭 링크를 제공한다.

시안 사진은 JPG/PNG/WebP만 받고 원본을 바꾸지 않은 1440px 이내 사본으로 처리한다. 최대 20장 및 총 용량 제한이 있으며 로컬 저장 실패·다른 탭과의 충돌을 알린다. 충돌 후 재조회 중 새로 입력한 문구도 보존한다.

## 검증

- 실제 UI에서 기본 28개 단계 전체 순방향, 마지막 이전 이동, 사진에서 보관함 연결을 확인했다. 선택하지 않고 다음으로 넘어가도 기존 조합을 변경하지 않는다.
- 글자 120%, 줄 간격 140%에서 전체값 반영, 초대글 개별 90%/90%, 개별 해제 후 전체값 복귀를 실제 계산 스타일로 확인했다. 반복 조절 시 배율이 누적되지 않는다.
- 320×568 / 390×844 / 430×932 / 1100×884 / 1440×1000에서 편집기·내장 청첩장 가로 넘침 0. 작은 화면의 하단 이전/다음은 44px이며 패널 안에서 옵션만 스크롤한다.
- 이름·초대글·이야기 제목의 실제 미리보기, 시안 사진 7→8장 추가와 순서 변경·되돌리기, 새로고침 복원, 내용 파일 내보내기/가져오기를 확인했다. 확인 후 이번에 만든 문구·사진 초안만 원복했다.
- 같은 음악의 재생 시간이 11.00→21.72초로 이어졌고 직접 정지 후 크기 변경에도 정지 상태를 유지했다. 기존 iframe과 audio를 다시 만들지 않는다.
- 실제 관리 화면은 로그인 전 ‘기존에 승인된 두 사람’ 안내와 Google 로그인만 표시한다. 운영 자료에 검증용 업로드·수정·게시를 하지 않았다.
- 최신 재로드 이후 관측한 브라우저 오류/경고는 없다. 이전 IAB 실행에서 URL 없는 MutationObserver 오류가 한 차례 관측되었으며 재현된 앱 기능 실패는 없다.

전체 검사 및 공개 배포 결과는 `PROGRESS.md`와 `live-check.json`에 기록한다. 실제 휴대전화 키보드·Google 로그인·지도 앱과 OS 공유 시트는 별도 실기기 확인 항목이다.

## 다음

두 사람이 내용 파일과 디자인 조합을 골라 확정한 뒤, 실제 운영 청첩장에 반영할 완료본을 만든다. 문구의 두 사람 간 온라인 동기화는 전용 저장 계약과 명시적인 반영 화면을 추가하는 후속 작업이다.
