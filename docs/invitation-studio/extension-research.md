# 조립실 추가 장면 조사 · 2026-10-29

이번 확장은 `/lab/studio/`의 선택 시안이다. 운영 VER5.6·VER6, 운영 API·사진·계좌·방명록 데이터와 관리 권한은 바꾸지 않는다. 추가 장면은 기본 숨김이며 고른 장면만 조합에 포함한다.

공식 문서와 공개 홈페이지 샘플 텍스트를 확인했다. 각 서비스의 결제 편집기나 모든 모바일 동작을 실행한 검증은 아니다. 업체의 ‘최초’ 등 마케팅 비교 주장은 채택하지 않았다.

## 편의 장면 세 가지

1. **하객 안내** — 접어 보는 질문 / 안내 카드. 현재 확정된 예식장·15층 벨리스홀·주소와 기존 지하철 안내만 표시한다. `wedding.guestInfo`에 실제 `parking`, `dining`, `shuttle`, `accessibility`, `children` 안내가 제공된 경우만 해당 질문을 만든다. 미입력 주차·식사·전화 정보나 임시 안내 문구는 하객 화면에 넣지 않는다.
2. **그날을 위한 작은 준비** — 체크리스트 / 단계형. 일정·교통·축하 메시지를 확인하고 관련 기존 장면으로 이동한다. 체크는 열린 미리보기의 메모리 안에서만 유지하며 참석 응답이나 서버 저장이 아니다. 이는 서비스의 공통 제공 기능이라고 주장하지 않는 자체 편의 제안이다.
3. **안내 카드 보관** — 티켓 / 엽서. 실제 일시·예식장 정보를 한 장에 담고 기존 이미지 저장·주소 복사·일정 저장 기능으로 연결한다. 시연이나 레이아웃 선택만으로 복사·다운로드·외부 이동을 실행하지 않는다.

RSVP, 두 번째 사진첩, 반복 인터뷰·타임라인은 추가하지 않는다. 선택/숨김/정렬 때문에 열린 질문·체크 상태·음악 노드를 다시 만들지 않는다. 실제 미정 정보 입력과 휴대폰 OS 저장 확인은 별도 후속이다.
