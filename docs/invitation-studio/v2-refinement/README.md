# Studio V2 — 장면 빼기·지도·서체 보완 (2026-11-01)

## 사용 방법

- 장면 선택 → 설정 제목 아래 **− 장면 빼기**. 모바일에서는 제목 옆에 있다. 기본 본문 장면과 선택해 추가한 장면에 적용하며, 표지·첫 손글씨·마지막 인사·빠른 메뉴는 고정 요소다.
- 목록 아래 **뺀 장면 → 다시 넣기**로 원래 순서에 복원한다. 문구·사진을 삭제하지 않으며, 이전/다음은 빠진 장면을 건너뛴다. 되돌리기도 지원한다.
- 뺀 장면은 콘텐츠 초안에 저장된다. 두 기기 사이에는 **공동 저장**, 파일로 옮길 때는 **문구·사진 포함 파일**을 사용한다. 기존 디자인만 저장하는 보관함/URL의 의미는 바꾸지 않았다.
- 전체 분위기 → 글씨체에서 리디바탕·함렛·프리텐다드 조합에 **고운바탕·SUIT·나눔 손글씨**를 더한 6종을 비교한다. 영어 손글씨와 음악은 유지한다.
- 네이버지도·카카오맵·티맵은 동일한 아이콘/이름/바깥 화살표 배치다. 작은 화면의 기존 span 숨김 규칙도 해제하여 이름을 한 줄로 유지한다.

## 구현 및 검증

- 기존 content.experience.values.hiddenScenes 계약을 사용하고 서버 권한/데이터/출처 허용 범위를 변경하지 않았다. 콘텐츠 로드 후 숨긴 목록 복원, 연속 클릭 보호, 입력 편집과 숨김 이력의 잘못된 병합 방지를 반영했다.
- 새 폰트는 로컬 원본과 OFL 라이선스를 번들에 포함한다. NanumPenScript TTF는 Google Fonts 원본 그대로다. 배포 검증은 Studio 폰트 4개만 명시적으로 허용하고 바이트 일치를 검사한다. 일반 MP3/폰트 중복 허용으로 넓히지 않았다.
- 전체 `npm run check`: **2,573 / 2,573 통과**. 서비스 빌드 통과. 서버 저장/명시적 공개 검사 7개 통과. 새 폰트/숨긴 장면의 서버 왕복, 기존 형식·이력·파일 복원 검사를 포함한다.
- 합성 로컬 UI: 이야기 빼기→복원, 추가 당일 패스 빼기→되돌리기, 서체 선택·실제 폰트 적용 확인. 운영 데이터에 검증용 저장·공개·계좌·방명록 쓰기 없음.
