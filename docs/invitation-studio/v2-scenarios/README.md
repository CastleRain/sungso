# Studio V2 — 완성 예시와 패널 크기 조절

2026-11-01. 운영 주소: https://sungso-wedding.vercel.app/lab/studio-v2/

## 변경한 동작

- PC에서 좌우 패널 경계를 드래그해 너비를 조절한다. 방향키(Shift로 크게), Home/End, 더블클릭 초기화도 지원한다. 너비는 해당 브라우저에 기억하며 모바일에서는 기존 하단 편집 패널을 사용한다.
- 장면 설정 맨 위에 **완성 예시로 시작**을 둔다. 예시는 기존 문구/사진 선택/목록을 지우지 않고 비어 있는 부분을 채우며 관련 표현을 전환한다. 한 번의 되돌리기로 예시 적용 전으로 돌아갈 수 있다. 이미 일부 행이 있는 목록에는 예시를 추가로 섞지 않는다.
- 새 선택 장면 5개(소개, 퀴즈, 부산 안내, 플레이리스트, 두 사진 비교)를 처음 넣으면 해당 예시를 함께 채운다. 빼 두었던 장면을 다시 넣을 때는 기존 내용을 유지한다.
- 서로의 기억을 입력하면 시점 전환이 켜지고 입력 중에도 미리보기에 반영된다. 시점/대화 표시 중에는 기존 3장 이야기와 해당 설정을 숨겨 중복을 없앴다. 기존 문구 자체는 보존한다.
- 표지의 꽃잎은 없음/로즈/아이보리로 선택한다. 최대 14개이고 표지가 화면 밖에 있거나 탭 숨김·모션 감소·효과 끄기·별도 오프닝/대화상자 표시 중에는 제거한다. 손글씨와 음악 플레이어는 재생성하지 않는다.

## 준비한 14개 예시와 직접 확인한 결과

| 장면 | 예시 | 확인한 동작 |
|---|---|---|
| 첫 화면 | 로즈 꽃잎과 손글씨 / 화이트 꽃잎과 여백 | 꽃잎 14개, 종류 변경, 효과 끄기 0개/켜기 복구 |
| 우리의 이야기 | 서로의 시선으로 | 성우·소희·함께 탭과 문구 즉시 반영, 기존 이야기 중복 숨김 |
| 우리의 이야기 | 한 문장씩 이어지는 대화 | 다음 문장으로 1→2문장 표시, 마지막에 처음부터 읽기 |
| 두 사람 소개 | 사진과 함께 넘기는 인터뷰 | 사진/질문/답변, 이전·다음 1/2→2/2 |
| 퀴즈 | 첫 만남을 맞혀 봐요 | 선택→정답·설명·사진·합성 참여 수 표시 |
| 부산 안내 | 예식 후 부산 한 장면 | 장소 2곳과 지도 링크 |
| 플레이리스트 | 우리의 배경음악 | Ever After, Us와 제공된 음원 링크 |
| 두 사진 비교 | 두 순간을 겹쳐 보기 | 실제 사진 2장과 경계 슬라이더 |
| 사진첩 | 사진이 이어지는 입구 | 프레임 전환과 하나의 필름 사진첩 |
| 날짜 | 예식 시각을 한눈에 | 15:30 예식 시간표 |
| 오시는 길 | 홀까지 이어지는 안내 | 펼쳐지는 약도와 15F 벨리스홀 |

| 마지막 인사 | 꽃잎으로 전하는 축하 | 축하 버튼에서 16개 꽃잎 효과 |

이야기/인터뷰/대사는 두 사람이 확인한 첫 만남·카페 운영 에피소드에 기반한 **수정용 제안 문구**다. 신부의 직접 발언이나 정확한 대화 기록으로 간주하지 않는다. 부산 산책 후보는 [부산시 광안리 안내](https://www.busan.go.kr/depart/ahgwanganri), [부산시민공원](https://citizenparkmap.bisco.or.kr/)를 확인했으며 두 사람이 실제 추천한 곳으로 바꾸도록 안내한다. 식사·주차 시간, 전화번호, 계좌번호는 만들어 넣지 않는다.
