# 전체 스타일·읽는 순서·장면별 표현 — 2026-10-28

## 선택의 역할

1. 전체 스타일: 색감 4종, 한글 서체 3종, 공통 스크롤 효과 4종.
2. 읽는 순서: 표지·마무리 사이의 필수 본문 7개. 화살표 또는 번호로 이동하며 숨김/누락은 허용하지 않는다.
3. 장면별 표현: 기존 표지·손글씨·초대글·날짜·이야기·사진첩 연출. 순서와 무관하게 선택한다.

장면 그대로는 기존 연출, 떠오르기와 선명해지는 장면은 절제된 공통 움직임을 더한다. 차분하게 읽기는 스크롤 동작만 멈추며 손글씨와 클릭 동작은 유지한다. 전체 효과 끄기와 OS 모션 감소는 별도로 모든 동작에 우선한다.

기존 V1의 URL/파일/브라우저 저장은 기본 순서와 효과로 호환한다. 추가된 순서와 효과도 저장·공유·JSON·되돌리기에 포함한다. 전체 페이지를 리로드하지 않는다.

## 구현과 확장

- `composition.mjs`의 CHOICES/CHOICE_KEYS는 시각 선택, ORDER_SECTIONS/DEFAULT_ORDER는 허용 섹션 목록을 담당한다. 순서는 알려진 ID만 중복 없이 허용하며 빠진 필수 항목은 자동 보충한다.
- `section-order.mjs`는 이미 동작하는 실제 노드를 재배치한다. 지도 iframe이 포함된 location은 움직이지 않고 나머지 구역을 앞뒤로 배치한다. 지원 브라우저에서는 moveBefore도 사용한다. 표지의 다음 링크와 빠른 메뉴는 바뀐 순서에 맞춘다.
- `scroll-effects.mjs`는 공통 읽기 리듬만 소유한다. 기존 개별 장면/앨범/도착 안내 스크롤과 클릭 상태는 분리했다. 스크롤 이벤트당 한 프레임만 요청하고 읽은 본문은 다시 숨기지 않는다.
- 새 기능은 별도 섹션과 허용 ID를 추가하거나 해당 장면의 CHOICES 선택지를 추가하는 식으로 확장한다. 서버/API/운영 모드는 조합 값으로 설정할 수 없다.

## 검증

- 최종 전체 `npm run check` 2,157개 통과. 전용 빌드247개 파일이며 이전 완성본/시안205개 파일의 바이트 보존을 검사한다.
- 5,040개 모든 순서를 URL/JSON으로 왕복하고, native moveBefore/대체 삽입 각각의 모든 순서에서 지도 노드 비분리·표지/마무리 고정·기존 노드와 선택 상태의 동일성을 검증했다.
- 실제 브라우저에서 사진7번·신부 측 어머니·자가용 선택 후 여러 구역을 연속 이동해 상태 유지 확인. 음악은 1.239→17.830초, 모바일 일반 조작에서도54.314→54.692초 연속 재생을 확인했다. 도구의 뷰포트 크기 변경 직후 재생이 멈춘 경우는 별도이며 실기기 화면 회전 재생까지 검증한 것으로 보지 않는다.
- 재배치 후 위치 안내 top20.4px, 빠른 메뉴 location 선택, 첫 링크와 전체 메뉴의 새 순서를 확인했다. 새 사진첩 첫 순서도 top20px로 이동했다.
- 떠오르기 실제 중간값 opacity.865/translate6.77px, 선명해지기 scale.989/blur.65px 확인. 차분하게 읽기는 날짜/도착 안내 transform none, 숨은 reveal본문0이며 원래 효과로 복귀할 수 있다.
- 순서와 공통 효과를 저장→새로고침→기본 조합으로 변경→저장 조합 불러오기로 확인했다. 검증용 저장 조합은 삭제했다.
- 320/390/1440px 편집·미리보기 가로 넘침0. 320px에서 끝의 방명록을 맨 앞으로 옮긴 뒤 편집 복귀 시 같은 선택란 top96px·초점 유지 확인.
- IAB에 출처 없는 MutationObserver observe 오류가 기록된다. 이전 실행에서도 관측됐으며 이번 선택/저장/재배치 기능 실패는 재현되지 않았다. 이를 오류0으로 보고하지 않는다.

실제 휴대전화의 터치 관성/프레임 속도/OS 지도 앱·공유는 별도 확인 대상이다. 조립실은 예시 계좌·체험 방명록이며 운영 데이터 변경은 없다.

다음: 두 사람이 전체 분위기와 섹션 순서까지 고른 조합을 비교해 운영용 완료본을 확정한다.
