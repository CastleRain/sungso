# Upper scenes · VER6.1 Studio

표지·초대/가족 소개·예식 날짜를 각각 선택하는 독립 모듈이다. 기존 필기 SVG, 신랑·신부 이름, 날짜/시간, 전체 MP3, 가족 정보와 캘린더 버튼을 그대로 사용한다. 본문이나 하객 정보를 새로 만들지 않는다.

| 구간 | 선택 | 연출 |
| --- | --- | --- |
| 표지 | cinema | 전체 사진이 둥근 액자로 작아지고 사진만 살짝 다가온다. |
| 표지 | curtain | 사진 위의 반투명 양쪽 장막이 바깥으로 벗겨지며 깊이를 만든다. |
| 표지 | aperture | 전체 사진에 둥근 창과 가느다란 안쪽 테두리가 생긴다. |
| 초대·가족 | letter | 초대 문장이 위에서 아래로 읽히고 종이가 평평하게 놓인다. |
| 초대·가족 | together | 양가 소개가 중앙의 & 쪽으로 가까워지고 가는 연결선이 그어진다. |
| 초대·가족 | ribbon | 초대 문구 뒤를 한 줄의 리본 선이 부드럽게 둘러싼다. |
| 날짜 | ticket | 기존 F 날짜 구성의 티켓이 짧은 구간에서 펼쳐진다. |
| 날짜 | orbit | 6일 주위에 한 점이 궤도를 따라 움직이며 멈춘다. |
| 날짜 | flip | 실제 달력 면이 위쪽 경첩을 중심으로 펼쳐지는 페이지 형태다. |

모든 연출은 자연스러운 세로 스크롤만 사용한다. 날짜의 기존 110px 고정 스크롤 여백은 제거했다. 정지 화면을 위해 계속 도는 타이머/프레임 루프는 없다. 실제 이동·리사이즈·설정 변경 때 한 프레임만 예약한다.

효과 끄기와 기기의 모션 감소 설정에서는 처음부터 읽을 수 있는 상태로 표시한다. 숨은 탭과 열린 대화상자에서는 프레임을 취소하며, 키보드로 일정 버튼에 초점을 보내면 달력이 완전히 펼쳐진 상태를 유지한다. 손글씨 재생/스크롤 잠금은 기존 오프닝 모듈이 맡고 이 모듈은 해당 잠금을 해제하거나 재생하지 않는다.

검사: 진행도 경계와 비정상 값, 설정 허용 목록, 장식 중복 없음, 기존 달력 DOM 보존, 단일 프레임 예약, 탭/대화상자 정지, 오프닝 잠금 존중, 키보드 초점 안정, 모션 감소, 해제 정리를 별도 단위 검사로 확인한다. 실제 화면의 픽셀/기하 확인은 통합 브라우저 QA에 기록한다.

## 2026-10-28 · 실제 Chrome 확인

로컬 빌드 `http://127.0.0.1:8033/lab/studio/preview/`를 별도 Chrome 탭, 390×844 viewport에서 확인했다. Windows의 세로 스크롤바를 제외한 본문 폭은 375px이며 가로 넘침은 0px였다. 이 검사에서 발견된 수정 필요 결함은 없다.

- `curtain/together/orbit`: 첫 화면의 전체 사진·완성 손글씨·이름·날짜/시간이 선명하게 보인다. PageDown으로 scrollY 0→717 이동 시 cover 진행도 0→1, 왼쪽 장막 transform이 단위 행렬→회전/이동 행렬로 변하고 가족 소개의 translate가 -22px→0px로 수렴했다. Orbit의 06, 실제 달력, 날짜·시간, 카운트다운이 한 카드에서 읽힌다. 원형 표시의 최종 회전 행렬을 확인했다.
- `aperture/ribbon/flip`: 새 진입 직후 19개 필기 획 중 첫 3개 offset이 1px이고 `intro-locked intro-running`이었다. 다음 관측에서 획이 0px, 이름 opacity가 1, 잠금 해제였다. 스크롤 후 표지 clip이 `inset(16px 12px round 27% 27% 24px 24px)`로 바뀌고 리본 선 offset이 0이 되었다. Flip 날짜 진행도 0.05193에서 달력 면의 rotateX 중간 행렬을 관측했으며 진행도 1에서 평평한 행렬로 돌아왔다.
- `cinema/letter/ticket`: 세 구성 ID가 실제 DOM에 반영되고 초대글 직접 링크에서 본문 top 44px, 초대문 clip 0으로 읽혔다. 빠른 메뉴의 예식 링크에서 날짜로 이동했고 캘린더 버튼이 실제 저장 선택창을 열었다. 기존 두 저장 링크와 2027년 3월 6일 오후 3시 30분을 확인했다.
- 효과 끄기 후 cover=0, intro=1, date=1, 날짜 transform=none, upper-scenes-active=false를 확인했다. 검사 후 효과 켜기로 원복하고 자체 생성 탭을 닫았다. 마지막 관측된 warning/error 로그는 0건이었다.
- OS 캘린더 파일 가져오기, 실제 휴대전화 터치/FPS는 이 검사에 포함하지 않았다. 사진의 원본 변경, 운영 데이터 쓰기, 외부 전송은 없었다.
