# VER6.1 Studio — 장면을 고르는 청첩장

2026-10-28. 기존 시안을 유지하면서 상단 연출을 늘리고, 6.1부터 쌓아 온 주요 장면을 골라 조립하는 별도 미리보기를 만들었다.

## 구성

- 표지 3종: 시네마 프레임 / 빛의 커튼 / 열리는 창. 실제 사진과 19획 손글씨 오프닝·이름·예식 일시를 유지한다.
- 첫 손글씨 4종: 한 획씩 쓰는 편지 / 두 줄의 흐름 / 번지는 잉크 / 빛이 지나간 자리. 표지와 독립적으로 고르며 음악을 끊지 않고 다시 볼 수 있다.
- 초대글·가족 소개 3종: 펼쳐지는 초대 / 마주 오는 이름 / 이어지는 리본.
- 날짜 3종: 날짜 카드 / 하루를 감싸는 궤도 / 넘겨지는 날짜. 원래 날짜·달력·남은 시간·일정 저장은 같은 자료다.
- 이야기 6종: 간결한 챕터 + A 선 / B 사진책 / C 빛 / D 별자리 / E 커피 편지의 주요 연출. 실제 사연 세 장은 공통이다.
- 사진첩 3종: F 스택 / G 필름 / 격자. 전체 7장, 확대·선택·전체 보기와 선택 복원을 유지한다.
- 도착 안내·교통편, 양가/받는 분 계좌 카드, 편지 방명록, 현재 위치 하단 메뉴는 F 구성으로 고정한다. 조합 변경 때 재생성하지 않아 선택 상태도 이어진다.

## 사용

`/lab/studio/`에서 추천 조합 3개 또는 개별 장면을 선택한다. 모바일은 장면 고르기/미리 보기로 전환하고, 전체 화면 링크로 청첩장만 볼 수 있다. 상단과 모션은 짧은 자연 스크롤 구간에서 드러나며 긴 고정 스크롤 구간은 추가하지 않았다.

최대 8개 조합을 이름과 함께 이 브라우저에 보관한다. 다른 기기에서는 미리보기/조립 링크 또는 JSON 파일을 사용한다. 저장되는 것은 6가지 시각 선택뿐이며 운영 자료를 변경하지 않는다. URL과 가져온 파일은 버전 1의 허용 목록만 반영한다. 1,944개 조합의 URL 왕복을 검사했다. 기존 첫 손글씨 선택이 없는 링크·파일·저장 조합은 원래의 획 쓰기로 열린다.

청첩장을 재로딩하지 않고 부분별 연출을 바꾼다. 음악은 같은 audio 요소를 사용하고, 조립실의 처음부터 보기는 명시적인 재시작이다. 독립 미리보기는 기존 자동재생 시도와 브라우저 차단 시 첫 조작 재생을 유지한다.

## 데이터·배포 경계

이 화면은 조립용 미리보기다. 실제 계좌 대신 명확히 표시한 예시 계좌를 쓰며, 체험 방명록은 studio 전용 로컬 키에만 저장한다. 부모 창의 같은 출처와 정확한 창 객체를 확인하며, 메시지나 URL로 운영 모드·API 주소·계좌를 지정할 수 없다.

기존 `/`, `/v6/`, A–E, F/G의 205개 파일은 SHA-256으로 보존한다. 새 공개 파일은 `/lab/studio/`에만 추가한다. 기존 관리 권한·API·Firebase 승인 도메인·실제 자료 변경은 없다.

## 실제 확인

- PC 조립실에서 추천 선택·개별 선택·즉시 적용·구역 이동 확인. 사진 7번을 선택한 뒤 격자→스택 전환 시 7번 유지, 신부 어머니 계좌 선택도 조합 변경 뒤 유지.
- 이름 있는 조합 저장, 파일 내보내기와 실제 파일 다시 불러오기, URL의 선택값 유지 확인. 검증용 저장 조합과 체험 메시지는 삭제했다.
- 봉투 작성창→체험 메시지 카드→삭제 확인. 복사 완료 표시는 확인했으며 실제 OS 은행 앱 붙여넣기는 범위 밖이다.
- 같은 audio의 시간 70.48→77.67→80.77초, 조합/구역 이동 후 재생 유지 확인. 부모 음악 상태와 청첩장 직접 정지 상태를 연결했다.
- 선택 조합의 예식 안내 PNG 1080×1440 생성 확인. 긴 조합 URL은 공유/ICS에 유지하고 PNG에는 읽을 수 있는 짧은 조립실 주소를 쓴다.
- 독립 미리보기 320/390/430/768/1440px 가로 넘침 0. 320px 큰 글씨 팝업은 288px 안에서 표시. 모바일 조립실 전환과 내장 미리보기(내용 폭 264px)도 가로 넘침 0.
- 효과 끄기 시 날짜 변형 none·숨은 reveal 본문 0. 상단 9개 선택의 실제 중간 모션·손글씨 진행·완료는 별도 [상단 QA](./upper-scenes.md)에 기록했다.
- 독립 Chrome 상단 검사 오류/경고 0. IAB 검수 도중 URL/소스가 없는 MutationObserver 오류가 관측됐으나 화면의 구성 컨트롤러는 정상 초기화했고 재현된 기능 실패는 없다. 이를 앱 오류 0으로 집계하지 않는다.

실제 휴대전화의 지도 앱 실행·공유 시트·OS 붙여넣기·프레임 속도는 별도 확인 대상이다.
