## 사용

`/lab/studio/`에서 전체 분위기 / 장면·순서 / 보관함 탭을 사용한다. 추천 조합 4개를 상단에 먼저 보여주며 이전 추천 6개는 접어서 보관한다. 전체 분위기는 색과 글·사진·움직임과 여백으로 좁혀 본다. 모바일은 미리보기와 접을 수 있는 하단 패널을 함께 보여주며, 전체 화면 링크로 청첩장만 볼 수도 있다.

현재 선택 요약을 누르면 왼쪽 안에 옵션이 펼쳐진다. 표현을 한 번 누르면 실제 구역으로 이동해 시연하며 별도 적용 버튼은 없다. 6개가 넘는 옵션은 검색과 더보기로 찾고, 다시 보기·변경 전 비교·시연 중지로 비교한다. 순서 변경 조작은 순서 편집을 켰을 때만 나타난다.

최대 40개 조합을 이름·별점(0~5)·메모와 함께 이 브라우저에 보관한다. 별점순/최근순, 4점 이상 필터, 이름·메모 검색, 여섯 개씩 더보기를 제공한다. 메모·이름·별점은 조합을 바꾸지 않고 수정할 수 있다. 다른 기기에서는 조합 링크 또는 단일/보관함 전체 JSON 파일을 사용하며 자동 동기화는 아니다. URL에는 허용된 시각 설정·속도·강도·추가 장면과 본문 순서만 담기며 메모·별점은 포함하지 않는다. 운영 자료를 변경하지 않는다. 기존 V1 조합은 기본 기능 표현으로 호환하며 잘못된 저장소나 다른 탭의 변경을 덮어쓰지 않는다.

청첩장을 재로딩하지 않고 부분별 연출을 바꾼다. 음악은 같은 audio 요소를 사용하고, 조립실의 처음부터 보기는 명시적인 재시작이다. 독립 미리보기는 기존 자동재생 시도와 브라우저 차단 시 첫 조작 재생을 유지한다.
