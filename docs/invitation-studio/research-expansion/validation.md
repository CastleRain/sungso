# 조사 기반 선택 확장 — 통합 확인

2026-10-29. 조립실만 확장하며 기본 하객용 청첩장·기존 버전·운영 데이터·회원 권한은 변경하지 않는다.

## 조사와 구현 범위

- 9개 업체에서 각각 5개 이상, 총 47개 공개 샘플 경로·구조를 조사했다. 그중 25개는 실제 브라우저 표지·본문도 확인했다. 나머지 22개는 공개 원문·설정 분석이며 모든 샘플의 모션을 실행 검증한 수가 아니다. 공식 기능 소개는 별도로 구분한다.
- 본문 크기 3종, 줄 간격 2종, 사진 톤 3종, 표지 구도 3종, 사진첩 열 수 3종·비율 4종, 엔딩 3종, 달력 표시 3종을 추가했다. 원본 비율 사진첩, 안내 슬라이더, QR 초대와 당일 패스 2종도 선택한다.
- 기본 7개에 하객 안내·체크리스트·간직하는 초대·우리의 약속·한 문장·감사 인사·당일 패스를 필요한 만큼 추가한다. 기본은 모두 꺼져 있다. 순서는 최대 14개이며 선택한 위치와 표현을 함께 저장한다.
- 기존 속도·강도 0.5–1.5배, V1 URL·별점·메모·40개 보관함·파일 형식을 유지한다. 보관함은 브라우저 로컬이며 두 기기 자동 동기화가 아니다.
- QR은 현재 허용된 조합의 공개 미리보기 URL만 로컬에서 인코딩한다. 불필요한 기본값을 생략해 밀도를 줄인다. PNG 저장은 직접 눌렀을 때만 실행한다. 실제 읽기 검사는 별도 QR 디코더로 조합 왕복을 검증했다.

## 실제 브라우저 확인

- 큰 글씨 선택 → 동일 초대글에서 변경 전·현재 비교. URL은 현재 선택을 유지한다. 사진첩 열 수·비율 설정은 격자·원본 배열에서만 노출한다.
- 사진 톤 변경 후 실제 사진에만 필터가 적용되며 QR은 바뀌지 않는다. 달력 동그라미·밑줄은 3월 6일의 실제 셀을 보여준다. 엔딩 사진, 당일 패스, QR 렌더를 확인했다.
- 음악 재생 시간이 0.11→22.72초로 이어지고, 직접 정지한 22.78초 상태는 다음 선택 후에도 유지됐다. 작성 중인 방명록 이름·본문과 열린 창을 유지했고 저장하지 않았다.
- 속도·강도 범위 끝값 0.5와 1.5가 URL에 반영됐다. 시연 중 직접 PageDown 입력으로 시연이 취소됐다. 안내 슬라이더의 임시 전환·복귀와 사용자의 직접 조작 우선은 컨트롤러 회귀 검사에 포함한다.
- 이름·별점 5·메모를 넣은 검증 조합을 로컬에 저장한 뒤 기본 조합으로 바꾸고 다시 불러와 새 설정과 추가 장면 복원을 확인했다. 실제 운영 자료 쓰기는 없다.
- 독립 미리보기 및 조립실 각각 320·390·430·1100·1440px에서 가로 넘침 0을 확인했다. 편집기 선택·탭의 최소 44px, 안내 버튼 48px, 모바일 미리보기와 하단 편집 패널이 겹치지 않음을 확인했다. 치수는 `screenshots/layout-direct.json`, `screenshots/layout-editor.json`에 보관한다.
- 연구 보고서의 화면 확인 필터와 업체 검색을 함께 적용해 TO OUR GUEST 5개만 남는 것을 확인했다.

## 제한

- 독립 미리보기의 관측 오류는 0이다. IAB 조립실에서 소스 URL이 없는 `MutationObserver.observe` 오류가 관측됐으나 해당 화면의 초기화·선택·시연에서 재현되는 기능 실패는 없었다. 조립실 오류 0으로 집계하지 않는다.
- 휴대전화 카메라의 QR 인식, 실제 지도 앱·OS 공유·일정 앱 및 장기 프레임 속도는 실기기 확인 범위다. 자동 음악 재생은 브라우저 정책에 따른 기존 첫 조작 대체를 유지한다.
- 하객 사진 업로드·개인 편지·방명록 답장·알림·QR 목적지 예약 변경은 서버와 권한 설계가 필요해 구현하지 않았다. RSVP·두 번째 사진첩은 추가하지 않았다.
