# Studio V2 — 고도화 명세 후속 구현

2026-11-01. 사용자가 승인한 미완료 개발을 기존 V2 위에 추가했다. RSVP·하객 사진 업로드·사진 설명은 기존 제외 요구를 유지한다. 하객 주소는 사용자가 공동 초안을 **공개하기** 전까지 기존 VER5.6을 유지한다.

## 어디서 사용하나요?

[Studio V2](https://sungso-wedding.vercel.app/lab/studio-v2/)에 승인된 두 사람의 계정으로 접속한다. 장면을 고르고 **문구·사진 → 이 장면에 더할 내용**에서 입력한다. 새 장면은 **장면 더하기**에서 선택한다. 입력·선택은 작업 초안이며 **공동 저장 · 공개 → 공동 초안 저장 → 공개하기 확인**을 거쳐야 하객에게 보인다.

## 실제 내용과 외부 설정

영상·음성·전화·주차/식사·시간표·층별 안내·인터뷰·퀴즈·추천 장소는 직접 등록한 값만 공개한다. 빈 새 장면은 하객에게 숨기고 스튜디오에는 입력 안내를 표시한다. 날짜/장소를 바꾸면 표시를 함께 갱신하고 기존 장소의 지도/교통 문구를 그대로 보여주지 않는다.

- 미디어 파일당 약 1.3MB, 합계 약 1.8MB, 최대 8개. 사진과 합쳐 공동 초안 3MB 한도를 사용한다. 짧고 압축된 사본이 필요하다. 비공개 조각으로 저장하며 공개 스냅샷이 참조하는 파일만 Range 응답으로 제공한다. 파일명·미사용 파일은 공개하지 않는다.
- 카카오 카드 공유는 JavaScript 키·서비스 도메인 등록이 필요하다. 미설정 시 일반 공유/복사를 유지한다. [공식 안내](https://developers.kakao.com/docs/ko/kakaotalk-share/js-link)
- Wallet은 이미 발급한 패스 URL 등록을 지원한다. 신규 발급·인증서 구매·유료 가입은 하지 않았다. QR·일정 저장 대안이 있다. [Apple 발급 안내](https://developer.apple.com/wallet/get-started/)
- 날씨는 예식 7일 전부터 부산 예보를 조회한다. 먼 날짜의 날씨나 평균 기온을 임의로 넣지 않는다. [Open-Meteo](https://open-meteo.com/en/docs)

## 검증과 범위

- 기능 브랜치 최종 전체 2,570개 검사 통과. 모션 끄기/늦은 재생/명시적 정지 회귀 검사를 포함한다. 서버 통합 브랜치 전체 2,216개·서비스 빌드 통과.
- 실제 Firestore Emulator 권한 16개 통과. 익명·미승인·승인 회원 모두 서버 전용 초안/공개 스냅샷/미디어 조각/참여 문서를 클라이언트에서 직접 읽고 쓰지 못한다. 회원 인증 서버를 통해서만 처리한다.
- 합성 브라우저에서 미디어 업로드, 직접 문구 편집/Undo, 날짜와 표지/달력/티켓, 음성·퀴즈·스탬프·하트·회원 답글, 파일/공동 저장/명시적 공개, 인쇄 PNG를 확인했다. 운영 초안·방명록·사진·계좌 QA 쓰기 없음.
- 편집기·하객 화면 모두 320/390/430/1100/1440px 가로 넘침 없음. 모바일 전체/절반/접기와 다음 장면 이동 확인. 형식 1 URL·40개 보관함·별점·메모·문구 포함 파일 왕복 유지.
- 물리적 마이크 권한, iOS/Android/카카오 인앱 실기기, 실제 키로 카카오 전송, Wallet 설치는 이 환경에서 실검증하지 않았다. 실제 콘텐츠 입력 후 두 사람의 휴대폰 확인이 필요하다. 항상 60fps나 소리 자동재생을 보장하지 않는다.
