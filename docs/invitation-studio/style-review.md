# 색감·글씨체와 변경 장면 확인 — 2026-10-28

## 구현

- 기존 분위기를 기본으로 팔레트 4종과 한글 서체 3종을 독립적으로 선택한다. 사진·Pinyon 손글씨·Antic 숫자는 보존한다. RIDIBatang/Hahmlet과 이미 배포된 Pretendard 가변 폰트를 재사용하며 새 외부 폰트 요청은 없다.
- URL, 로컬 저장 최대 8개, JSON, 되돌리기에 두 선택을 포함한다. 이전 V1 조합은 원래 분위기로 열린다. 예식 안내 PNG도 선택한 색감·한글 서체를 반영한다.
- 색감/서체는 초대글과 가족 소개, 장면 선택은 해당 구역으로 이동한다. 이동 뒤 ‘지금 바뀐 장면’ 안내와 짧은 부분 등장 동작을 보여 준다. 동일 선택을 다시 누르면 다시 볼 수 있다. 문서나 음악을 다시 로딩하지 않는다.
- 빠른 연속 선택·실제 사용자 스크롤/키 입력·숨은 탭·팝업은 이전 예약과 재생을 정리한다. 글꼴 준비 대기는 1.5초로 제한한다. 효과 끄기·기기 모션 감소에서는 움직임 없이 안내와 내용을 보여 준다.
- 모바일 선택은 미리보기로 전환하고 ‘계속 고르기’는 편집 위치·초점을 복원한다. 복원 직전에 사용자가 새 입력란을 선택했다면 그 입력을 방해하지 않는다. PC 바깥 스크롤 대신 iframe 내부만 이동한다.

## 실제 확인

- IAB에서 12개 색감×서체 조합의 실제 적용, 웹폰트 로딩, 본문 굵기와 넘침 0을 확인했다. 단정한 편지 RIDIBatang 400, 또렷한 세리프 Hahmlet 500, 모던 StudioModern 400이다.
- 색감/서체/날짜 선택 시 목표 구역 위 20px와 해당 선택 이름의 알림을 확인했다. 같은 선택을 다시 클릭할 때도 안내가 재생된다.
- 모바일 390px에서 선택→미리보기→계속 고르기의 편집 위치 복원, 음악 87.247→88.188초 연속 재생을 확인했다. 320px 편집·미리보기와 1440px PC에서 가로 넘침 0이다.
- 밤빛 네이비/또렷한 세리프 조합을 이름 붙여 저장한 뒤 새로고침하여 두 선택이 남는 것을 확인했다. 에이전트가 만든 검증용 조합은 삭제했다.
- 효과 끄기에서 정적인 변경 안내와 본문 불투명도 1을 확인했다. 밤빛 네이비/모던 조합으로 예식 안내 PNG 1080×1440 생성도 확인했다.
- 전체 `npm run check` 2,141개 통과. 최초 제한 환경 실행의 로컬 fetch EACCES는 허용 환경에서 재실행하여 해소했다. 기존 205개 파일을 보존하는 청첩장 전용 빌드 244개 파일을 확인했다.
- IAB 로그에 출처 없는 MutationObserver 오류 2건이 기록되어 오류 0으로 보고하지 않는다. 같은 도구에서 이전에도 관측된 오류이며 이 실행의 선택·저장·재방문·내보내기 실패는 재현되지 않았다.

## 범위

실제 휴대전화의 글자 픽셀 렌더링·프레임 속도·OS 지도/공유는 별도 확인 대상이다. 이 조립실은 예시 계좌와 체험 방명록을 사용하는 미리보기이며 운영 데이터·권한·서버·기존 완성본을 바꾸지 않는다.
