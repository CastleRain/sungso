# 조립실 통합 코드 검토

2026-10-28, 독립적인 소스 검토. 실제 브라우저·실기기 관찰과 구분한다.

## 확인한 경계

- 조립 설정은 표지·초대글·날짜·이야기·사진첩의 허용 ID만 받는다. URL·JSON 파일·로컬 보관·부모 창 메시지가 데이터 모드나 임의 경로를 선택하지 않는다.
- 편집기와 미리보기 양쪽에서 정확한 origin과 상대 창 identity를 확인한다. 다른 출처나 형제 iframe 메시지로 구성을 바꾸지 않는다.
- 미리보기는 데모 어댑터를 사용한다. 계좌는 예시, 방명록은 조립실 전용 localStorage 키이며 서버 쓰기 기능이 없다. 입력 문구와 저장된 조합 이름은 textContent로 렌더한다.
- 설정 변경은 하나의 미리보기 문서 안에서 이뤄진다. 음악 요소, 방명록, 계좌 제어기를 재생성하지 않는다. 사진첩도 스택·필름·격자 전환 사이에 같은 제어기를 유지해 선택된 사진을 보존한다.
- 이야기/사진첩의 18개 조합, 효과 끄기·시스템 모션 감소·탭 숨김·팝업·초점·정리를 포함한 내용 모듈 검사 7개를 통과했다.

## 통합 중 발견해 전달한 수정 항목

1. 초기 iframe ready와 load가 같은 구성을 두 번 적용한다. 같은 구성 재적용은 손글씨 종료·팝업 종료 없이 확인 응답만 보내야 한다. 루트가 동일 구성 판별을 추가한 것을 소스로 확인했다.
2. 모션 제어기 초기화 실패 시 `motionReady:false`를 편집기가 처리하지 않아 준비 표시가 계속될 수 있었다. 오류 상태와 전체 화면 보기 대체를 builder 담당자에게 전달했다.
3. 구성 변경 중 열린 사진/이야기 창을 닫으면 기존 `#photo/N`, `#story/N`, `#album`과 dialog history state가 남을 수 있었다. 부모의 후속 이동이 없는 실행 취소 등에서도 안전한 섹션 주소로 정리하도록 전달했다.
4. PNG 예식 정보에 새 조합 URL 전체를 한 줄로 그리면 긴 query 때문에 최소 글씨 크기에서도 영역을 넘쳐 저장이 실패할 수 있었다. 표시용 짧은 주소와 조립 시안 표기로 수정하도록 전달했다. 공유·일정 링크는 전체 구성을 보존해야 한다.
5. 편집기의 서체 이름 `Pinyon Script`, `Antic Didone`가 실제 선언 `PinyonScript`, `AnticDidone`와 달랐다. builder에게 수정을 전달했다. 청첩장 본문은 올바른 선언을 사용한다.

음악 재생 허용 상태와 실제 재생 상태는 구별된다. 브라우저의 자동재생 제한이나 미리보기 내부의 명시적 정지 뒤에는 부모의 음악 허용만으로 소리가 시작되지 않을 수 있으므로 실제 아이콘 상태와 안내를 브라우저에서 확인해야 한다.
