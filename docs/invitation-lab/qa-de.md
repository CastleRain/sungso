## 실제 검증에서 수정한 점

- 처음에는 섹션 제목 위치를 모션 기준으로 삼아 컵과 사진이 화면에 들어오기 전에 대부분의 동작이 끝났다. D/E 모두 실제 `.story-entry`와 `#gallery-grid` 위치를 기준으로 바꿨다. 위 표는 수정 후 재확인 값이다.
- 공통 이야기 페이지의 WAAPI transform이 테마별 CSS 등장 동작을 덮는 문제를 부모 작업에 전달했다. 공통 코드가 D/E를 제외하도록 수정된 빌드에서 E의 편지 펼침 중간 transform을 확인했다.
- 기존 색/사진/정보·native scroll을 유지했다. 생성된 카페 사진, 임의 사연·날짜, 지속적인 별 파티클은 넣지 않았다.

## 자동 회귀 검사

`node --test apps/invitation-lab/tests/themes-de.test.mjs apps/invitation-lab/tests/audio.test.mjs`

총 28개 통과. 모션 진행률/사진 수/compact 모드, 효과 끄기·모션 감소·숨은 탭·열린 dialog의 프레임 중지, 동적 사진 갱신, 정리, 오디오 late-play race, 자동재생 차단, 신뢰할 수 있는 입력, 비교 화면 재생 허가, 직접 정지 보존, 안내 1회 표시, 트랙 제목을 검사한다. 브라우저 정책과 실제 휴대폰에서의 재생 허용은 별도다.

### 추가 독립 경계 검사

`node --test apps/invitation-lab/tests/gallery-boundaries.test.mjs apps/invitation-lab/tests/core-boundaries.test.mjs apps/invitation-lab/tests/ui-copy.test.mjs`

추가 18개 통과. 프로덕션 모듈의 실제 함수를 최소 DOM 대역에서 실행했으며 단순 소스 문자열 검사는 아니다.

- `setupGallery`: 사진 0/1/20장, 최대 6장 미리보기·전체 20장, 이전/다음 순환, 키보드, 세로 스크롤과 가로 스와이프 구별, 썸네일/원본 실패 뒤 재시도, 목록 전체 교체·선택 항목 삭제·빈 목록 전환을 확인했다.
- 목록 갱신 시 열린 사진 창에 이전 사진·저장 링크·카운터가 남는 결함 2건을 처음 검사에서 재현했다. 공통 구현의 진행 중 사진 모션 취소와 열린 창 재표시 수정 후 두 회귀 검사가 통과했다.
- `countdown`·달력: 한국시간 3월 5일 23:59:59 → 6일 자정, 예식 직전/시작/이후, 7일 자정의 날짜·시간·문구 상태를 확인했다. UTC로 같은 순간을 전달해도 결과가 같다.
- `calendarEvent`: 다섯 시안의 정확한 공개 URL, 예식 UTC 시각, CRLF, UTF-8 75바이트 접기와 한글 보존, 텍스트 쉼표/세미콜론/개행 이스케이프를 확인했다. 로컬 공유는 비교용 쿼리·사진 해시를 제거한다.
- `copyText`: 브라우저 클립보드 성공 시에만 성공 토스트 표시, 클립보드 거부+legacy 예외/false 모두 수동 복사 창으로 이동, 정확한 문자열·포커스·선택 상태와 임시 입력란 정리를 확인했다. 실제 운영 계좌를 사용하지 않았다.
