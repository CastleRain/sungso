# 공통 기능 통합 QA

2026-10-28, 청첩장 전용 로컬 빌드와 실제 Chromium 인앱 브라우저에서 확인했다. 운영 방명록·계좌·관리 API에 검증 자료를 쓰지 않았다.

## 실제 조작 결과

- 첫 화면: 손글씨 19개 획, `intro-running`에서 획 offset 1, 완료 후 0. 시작 중 스크롤 0, 빠른 메뉴 숨김. Escape로 즉시 완료·스크롤 해제. 기존 SVG와 MP3 경로 유지.
- 음악: audio 1개. 첫 실제 조작 후 재생, 이야기·사진 확대를 왕복해도 이어짐. 직접 정지한 뒤 이야기 이동으로 다시 켜지지 않음. 기기에서 출력된 소리를 직접 청취한 검사는 아니다.
- 사진첩: 전체 7장, 7번째 원본 로드, 전체 앨범→확대→뒤로→앞으로→닫기에서 사진 번호와 앨범 복원. 사진 창과 앨범이 겹쳐도 배경 스크롤 잠금 유지.
- 이야기: 두 번째 이야기 직접 링크, 세 번째로 이동, 닫기·본문 복귀. 임의 교제 날짜나 새로운 사건을 만들지 않았다.
- 계좌: 신부 측 선택 후 예시 번호를 복사하여 브라우저 클립보드 `0000000004`와 일치. 양가 선택·행 구분·복사 완료 표시. 실제 번호나 송금 링크 없음.
- 방명록: A에 체험 메시지 작성→새로고침 후 유지→확인창에서 삭제. `<b>` 문자열이 태그로 실행되지 않고 문자로 표시됨(자식 노드 0). 작성·삭제는 시안별 localStorage에만 적용.
- 빠른 보기: 날짜·장소, 위치/사진/이야기/계좌/메시지 이동, 큰 글씨 전환. 팝업 열림 중 배경 스크롤을 막고 닫으면 해제. 다른 sungso 앱 링크 없음.
- 큰 글씨/효과 끄기: 큰 글씨 상태에서 좁은 화면의 가로 넘침 없음. 효과 끄기 후 숨은 reveal 0, 사진 transform none, A 연결선 완성 상태. 키보드로 조작한 항목은 숨은 채로 남지 않음.
- 공유/일정: 시안별 canonical·OG·ICS는 각 A–E의 공개 URL. ICS·Google 일정 두 선택을 제공하며 예식 종료 시간은 임의로 만들지 않음. 사진 저장은 원본 파일, 예식 정보 저장은 1080×1440 PNG. 실제 PNG 결과는 `qa-abc.md`에 캡처.

## 반응형과 길이

- 320×568, 360×800, 390×844, 430×932, 768×900, 1440×900 및 844×390에서 실제 viewport 값을 확인했다. 공통 UI와 E에서 가로 넘침 0·표시된 본문/버튼 내부 글자 잘림 0. A–D의 추가 모바일/PC 근거는 개별 QA에 있다.
- 390×844와 폰트 loaded 상태에서 A 본문 6,880px, E 6,791px. 포함된 예시 계좌 구역은 각각 818/797px다. 기준 v6 로컬 화면은 계좌가 없는 상태에서 5,523px다. 계좌 구역을 제외한 관측 길이는 A 6,062px(+9.8%), E 5,994px(+8.5%)다. 전체 길이가 같다고 주장하지 않으며, 비교 시안에는 체험 계좌와 비교 안내가 추가되어 있다.
- 초기 빠른 메뉴/건너뛰기 겹침, 모달 뒤 배경 스크롤, 테마 이야기와 공통 전환의 충돌을 수정했다. 실제 갤러리 렌더 교체 검사로 열린 사진의 오래된 원본/다운로드/카운터가 남는 문제도 수정했다.

## 자동 검증과 범위

`gallery-boundaries`, `core-boundaries`, `ui-copy`는 실제 모듈을 실행한다. 0/1/20장·6개 미리보기·순환·이미지 실패/재시도·목록 변경·선택 삭제·한국시간 전/당일/익일·ICS 75바이트 접기·복사 실패 시 수동 선택을 검사한다. 테마/음악 검사에는 효과 끄기·모션 감소·탭 숨김·정지 상태 보존이 포함된다.

리소스 용량의 재현 가능한 측정은 `resource-budget.json`에 있다. LCP/CLS 및 저사양 휴대폰 프레임 속도는 실제 측정하지 않았으므로 통과 수치로 표시하지 않는다. iOS/Android 실물 기기의 자동재생 허용, OS 공유 시트·캘린더 가져오기·지도 앱 전환·사진 다운로드와 실제 카카오톡 미리보기는 사용자 기기에서 별도 확인할 항목이다.

현재 시안은 비교용이다. 계좌는 예시, 방명록은 기기별 체험 데이터, 사진은 현재 공개된 7장의 스냅샷이다. 기존 `/`와 `/v6/`의 실제 데이터·관리 권한은 그대로 유지한다. 선택된 시안을 운영본으로 승격하는 작업은 별도 선택 후 진행한다.
